## 定位

发票识别处理纸质发票从扫描到归档的全流程。

### 四个核心功能

| # | 功能 | 说明 |
|---|------|------|
| 1 | 识别和读取内容 | 上传扫描件 → OCR → 结构化数据 |
| 2 | 展示票据核对 | 人工校对 OCR 结果，修正错误字段 |
| 3 | 生成可打印的 PDF 排版 | A4 排版预览，旋转，导出打印用 PDF |
| 4 | 导入历史 / 导出整理后的发票 | Excel 导入过往台账；导出 PDF + 原件 + Excel |

边界原则：

| 在本页面做 | 不在本页面做 |
|---|---|
| 上传/识别/校对发票扫描件 | 登记收票到项目（→ `finance-ticket`） |
| 打印排版和导出 | 发起付款申请（→ `finance-payment`） |
| 维护发票台账 | 开票申请（→ `finance-billing`） |
| 导入 Excel 历史台账 | |

## 一、业务流程

### 1.1 扫描件识别流程

```
① 上传扫描件 ──→ ② OCR 识别 ──→ ③ 人工校对 ──→ ④ 打印 ──→ ⑤ 归档入账
   PDF/图片/文件夹    自动提取字段    核对/修正字段    A4排版打印    进入发票台账
        │                │
        │                ├─ 重复检测 → 标记"重复已排除"
        │                └─ 识别失败 → 标记"待人工录入"
        │
        └─ 批量上传 → 批量识别（队列）
```

### 1.2 Excel 导入流程

```
① 导入 Excel ──→ ② 字段映射 ──→ ③ 重复检测 ──→ ④ 直接入台账
   历史发票台账     列名→字段对应    发票号匹配      无扫描件，纯数据
                                       │
                                       └─ 发票号匹配已有记录 → 数据补充
```

### 1.3 打印流程

```
校对完成 ──→ 勾选待打印发票（支持全选）──→ 排版预览 ──→ 生成 PDF
         ──→ 调起系统打印对话框 ──→ 打印确认弹窗 ──→ printCount+1
         ──→ 归档入台账
```

打印确认：系统无法可靠检测用户是否真的执行了打印（`afterprint` 事件无法区分打印/取消），因此采用**打印确认弹窗**——打印对话框关闭后弹出"是否已完成打印？"，用户确认后计数+1。

### 1.4 导出流程

```
选择发票范围 ──→ 弹出文件夹选择器 ──→ 选择导出格式 + 文件夹结构 + 命名规则
                 ├─ 打印 PDF（A4 排版）
                 ├─ 导出原件（原始扫描件，按文件夹组织）
                 └─ 导出 Excel 台账
```

导出原件时可选文件夹组织维度（采购方/票据类型/开票月份），支持多级嵌套。文件名称规则可配置。

> 导出文件夹选择和命名规则为全局通用规范，适用于所有模块的文件导出。

## 二、数据模型

### Invoice（发票）

```ts
interface Invoice {
  id: string

  // ── 文件信息 ──
  fileName: string
  filePath: string            // 无扫描件时为空
  fileSize: string
  pageCount: number

  // ── 识别结果 ──
  invoiceType: string         // 增值税专用发票 | 增值税普通发票 | —
  invoiceNumber: string       // 发票号码（全号）
  invoiceDate: string         // YYYY-MM-DD
  buyer: string               // 购买方名称
  buyerTaxNo: string          // 购买方税号（空→预警）
  seller: string              // 销售方名称
  sellerTaxNo: string         // 销售方税号
  amount: number              // 不含税金额
  taxAmount: number           // 税额
  totalAmount: number         // 价税合计
  taxRate: string             // 税率
  remark: string              // 票面备注（自动提取项目名称）

  // ── 货物明细（OCR 提取） ──
  items: InvoiceItem[]

  // ── 关联 ──
  projectId: string | null
  projectName: string
  supplierId: string | null

  // ── 状态 ──
  ocrStatus: 'pending' | 'processing' | 'done' | 'failed'
  reviewStatus: 'unreviewed' | 'reviewed'
  accountStatus: 'none' | 'confirmed'
  dupStatus: 'normal' | 'duplicate'

  // ── 打印 ──
  printCount: number          // 打印次数
  lastPrintedAt: string | null

  // ── 来源与排版 ──
  source: 'scan' | 'excel'
  printRotation: number       // 0/90/180/270

  // ── 审计 ──
  ocrConfidence: number | null
  confirmedAt: string | null
  createdAt: string
  updatedAt: string
}

interface InvoiceItem {
  name: string                // 货物名称
  spec: string                // 规格型号
  unit: string                // 单位
  quantity: number
  unitPrice: number
  amount: number              // 金额
  taxRate: string
  taxAmount: number
}
```

### 状态流转

```
上传 → ocrStatus: pending → processing → done | failed
                                ↓ (done)
                           重复检测 → dupStatus: duplicate
                                ↓ (normal)
                           reviewStatus: unreviewed → reviewed（校对确认）
                                ↓
                           打印（可选）→ printCount++
                                ↓
                           accountStatus: confirmed（归档入台账）

Excel 导入 → ocrStatus:done, reviewStatus:reviewed, accountStatus:confirmed, source:'excel'
```

## 三、Tab 结构

```
[上传 +]  [校对与排版 5]  [发票台账 20]
```

三个 Tab，数据分区互斥。

| Tab | 数据范围 | 用途 |
|-----|----------|------|
| 上传 | — | 上传入口 + 按购买方金额汇总 |
| 校对与排版 | `ocrStatus=done AND dupStatus=normal AND accountStatus≠confirmed` | 校对+打印排版+归档 |
| 发票台账 | `accountStatus=confirmed OR source='excel'` | 总台账+导出+导入 |

### 5.4 批量模式 — 中栏（打印排版预览）

#### 勾选打印

| 税率 | 右 | mono |

#### 预警机制

| 条件 | 表现 |
|------|------|
| 购买方税号为空 | 税号输入框黄色边框 + 预警图标 |
| 单号与历史入账重复 | 单据编号红色边框 + "与已入账 #xxx 重复" 提示 |
| OCR 置信度低的字段 | warn 色边框 |

#### 下半部分：货物明细表格

|----|------|

不使用传统按钮排列。采用**操作条**设计：

```

```

- 废弃：danger 样式，靠左隔开
- 重新识别：次要按钮
- 打印选中：打印中栏已勾选的发票
- 归档入账：主操作，校对确认 + 入台账

### 5.6 打印流程

1. 在中栏勾选要打印的发票（或全选）
2. 点击"打印选中"
3. 系统生成 A4 排版 PDF
4. 调起系统打印对话框
5. 打印对话框关闭后，弹出确认："是否已完成打印？"
6. 用户点"已打印" → 所有勾选发票 `printCount += 1`，`lastPrintedAt` 更新
7. 用户点"取消" → 不计数

## 八、重复检测规则

| 场景 | 检测依据 | 处理 |
|------|----------|------|
| 扫描件识别后 | `invoiceNumber` 精确匹配 | 标记 `dupStatus=duplicate` |
| Excel 导入时 | `invoiceNumber` 精确匹配 | 合并到已有记录（补充空字段） |
| 扫描件匹配 Excel 导入记录 | `invoiceNumber` 精确匹配 | 关联扫描件到已有记录 |

## 九、开票因子计算器 `/finance/invoice/factor`

独立页面，辅助计算开票金额的因子组合方案。

### 布局：两行两列

```
┌─── Row 1 ──────────────────────────────────────────────────┐
│  输入面板                    金额卡片 (3列，唯一复制入口)     │
│  目标含税金额                价税合计 │ 不含税 │ 税额         │
│  税率 [13][9][6][3][1]       大写(复制)                     │
│  小数位                                                     │
└─────────────────────────────────────────────────────────────┘
┌─── Row 2 ──────────────────────────────────────────────────┐
│  开票因子表                  组合方案                        │
│  名称│单位│单价│上限│删       [计算组合] 最多 N 条            │
│  [+ 新增] [粘贴导入]         共 N 种 · Xms                  │
└─────────────────────────────────────────────────────────────┘
```

因子表保留列：名称、单位、含税单价、上限、删除。

粘贴导入：Tab 分隔，`Ctrl+V` 或"粘贴导入"按钮。

性能：Web Worker + 2 秒时间限制 + 5000 组合硬上限。

## 十一、验收要点

1. 三个 Tab 数据互斥：上传（入口）、校对与排版（待处理）、台账（已确认+导入）
2. Tab 1 纯上传 + 按购买方金额汇总，无统计卡片
3. Tab 2 校对和打印排版在一起，三栏联动
