# 红圈结构观察（2026-07-11）

> 非权威原始观察。样本为当时一个参考项目及所能安全读取的全公司页面；此文件只保存结构，不包含真实业务原件。当前字段、规则、能力和完成状态直接查 [CONTEXT](../../CONTEXT.md)、[页面规格](../rewrite/pages/)与[运行参考登记](../design/runtime-reference-audit.md)。

原调查中的 DC 差距动作、组件新建计划、优先级、真实资料装入设计种子建议以及旧执行队列已经退出当前阅读入口。原全文可从[固定 Git 来源](https://github.com/zodea/crm-new/blob/c16869fcbf954dddd46143839afe5790f3828f1a/docs/research/red-circle-ui-gap-2026-07-11.md)定位。

## 1. 表单和全局交互观察

| 参考页面行为 | 当时观察到的结构 |
| --- | --- |
| 检索型下拉 | 输入远程查询、匹配高亮、最近选择区、清空及关联对象新建入口、方向键与 Enter |
| 依赖级联 | 项目未选时说明依赖；项目过滤合同，选合同后带出只读合同情况 |
| 明细网格 | 添加、复制、删除、关联单据选择、模板下载、导入及 Excel 编辑入口 |
| 校验 | 字段红框与顶部提示并存；未通过时不保存 |
| 保存动作 | 取消、草稿、保存并新建、提交、保存及保存后关闭选项 |
| 实体新建 | 部分大单据先选业务类型，再进入带锚点分区的整页表单 |
| 布局配置 | 页面提供列数、对齐及自定义入口；未据此确认瑞航应实现 |
| 取消 | 当时参考页面直接关闭；瑞航未保存保护按自己的现行契约 |

这些观察不决定瑞航保留最近选择、弹窗实体表单或完整审批。公共原语及表单形态只看 [KitUI](../design/kit-ui-component-specs.md)、[DESIGN-SYSTEM](../rewrite/DESIGN-SYSTEM.md)与 [ADR 0014](../adr/0014-full-page-entity-forms.md)。

## 2. 列表结构观察

当时记录了业务视图切换、左侧分类树、随筛选联动的底部汇总、部门范围、列头筛选、导入导出和分页。样本为桌面结构，不证明完整键盘、手机容器或每个菜单均已验证；当前对应页面需按运行参考登记重新核对，不能据本观察计为运行通过。

## 3. 项目详情结构

观察到详细资料、成本预算、施工合同、支出合同、票税、资金、往来款、扣返款、支付明细、物资、竣工验收及保修等关联 Tab。经营数字为关联单据形成的只读展示；右栏包含成员、文件、评论、跟进人和动态。样本也有阶段任务及完成计数，但不能据此为瑞航新增审批驱动或人员权限模型。

## 4. 金额链和跨对象观察

收入侧可从施工合同进入收入结算、开票和收款；支出侧可从预算进入合同、结算、付款申请和支付。部分金额支持进入来源列表，未挂预算项的数据另有入口。样本联营场景存在公司收款、退往来款和线下工程支付的不同展示，未据此建立瑞航现金计算公式。

参考对象中的“支出合同”、补充协议、联营相关方和付款分类只是采集时命名；瑞航稳定身份、成本和支付关系只在 [DATABASE](../rewrite/DATABASE.md)维护。旧观察的金额勾稽不能覆盖后来确认的清偿证据、工资例外、管理费配置或来源未知边界。

## 5. 审批呈现

当时观察到节点与人员状态、右栏时间线、相邻同人节点提示、提交版次和当前审批人。它们不构成瑞航审批规则；当前范围排除完整审批引擎，页面只能展示已有真实状态和审计事实。

## 6. 参考分类词表

当时付款申请菜单区分合同、无合同、预付款、项目管理费、项目费用及公司付款。收入侧变更区分变更洽商、签证、索赔和认价；支出侧变更按原因呈现。结算区分过程与完工，分包结算区分专业、劳务和零星用工。分供方有类别与业务类型，收票有业务分类和票种。该词表仅便于定位原参考菜单，不作为瑞航枚举或新增业务类型授权。

## 7. 样本和观察限制

- 当时收尾单据、收入变更和罚扣页面样本为空；这只能证明观察时空态，不能证明瑞航应排除这些流程或编造正式数据。
- 样本没有仓储业务记录，采用合同、结算和付款链；不能据此降低或取消物资库存、调拨、盘点义务。
- 项目经营数字未观察到直接编辑入口，不据此否认项目主档的合法编辑能力。
- 付款明细到货、集中付款、其他合同子菜单及更多付款类型当时仍需补采；旧计数、子集金额、往来口径和收款累计差异没有完整解释，不能直接作为当前事实。

独有观察与未验证范围继续保留；现行规则、实测入口和完成证据由各自权威与运行登记维护。
