# 工人实名资料、照片与工资名册归档

## Parent

父票 #412；协作 Refs #407、#406。以已合并基线 `084e1e4b` 为起点，不重复 P0–P7 已完成链路。

## Problem Statement

工资已保存原成员与实际发放，但当前工作簿没有完整实名名册和证件照、银行卡照。工人中央附件尚未接通，旧工人迁入只保留基础身份和日薪。以当前主档补写旧工资会伪造历史；工资权限也不能自动授予完整私密人员资料。

## Solution / What to build

2026-09-22 用户已选择：工资工作簿关联独立、有日期、不可变的名册归档版本；后来补充产生新版本，不称旧原件；完整身份证、银行资料和照片须有单独工人私密资料权限。

经办人在工人整页维护实名资料、劳动合同签订事实和明确用途的两类照片。获得私密权限后，可针对同项目所选已发工资的原冻结成员建立带日期的名册归档，查看版本及下载实际名册和照片原件。工资正式编号和工作簿组合由另一工作单元消费本票接口。

## User Stories

1. 作为资料经办人，我要在工人 owner 的整页维护劳动合同签订及两类照片，保存后冷刷新回读同一版本。
2. 作为资料经办人，我要按用途选定照片，不根据文件名自动判断证件照或银行卡照。
3. 作为资料经办人，我要替换照片形成新原件身份，旧归档继续引用旧字节。
4. 作为名册经办人，我要选择同项目的已发 A/C1/C2 工资，后台从原冻结成员确定范围，不能手填任意工人扩大私密读取。
5. 作为名册经办人，我要看到负责人、零分配人员及同名异 ID，不因当前转组或离职丢掉原成员。
6. 作为名册经办人，我要明确资料登记日期与实际归档时间，当前补充资料不冒充工资发放时资料。
7. 作为名册经办人，我要看到缺身份证、劳动合同、日期、照片正文和失效关系的独立缺口，不能把缺失当零或附件齐全。
8. 作为名册经办人，我要在来源变化时保留输入并重新核对，丢失响应时恢复同一个提交。
9. 作为查看人，我要凭独立工人私密权限读取范围内名册和照片；仅工资读写或一般工人读取权限不能得到这些资料。
10. 作为历史查看人，我要重开旧版本时看到当时固定的字段和照片，之后改名、换照片和转组不能重写旧版本。
11. 作为迁移经办人，我要完整迁入旧实名字段、worker owner 原件及缺口，未知照片用途保留未知，不能猜造。
12. 作为迁移经办人，我要重复迁入不覆盖日常资料，回滚有归档引用时整批拒绝，失败后原事实保持不变。

## Implementation Decisions

- 复用现有独立 `worker:sensitive:read` 能力名称，建立实际授权读取语义；默认工资能力不包含它。工人维护还要求 `worker:write`，名册新版本要求工资读写与私密读取。
- 普通工人列表/详情仍脱敏。私密资料与照片归工人 owner；不可变名册只保存带来源版本的投影与原件引用，不新增工资金额账或私有人事主档。
- 所选已发工资、项目、来源、会话、完整冻结成员、资料版本及照片摘要在服务端复验。无完整冻结成员证据的旧工资明确阻断该份归档，保留原工资可读性。
- 工作区事务内保存不可变版本、照片、回执和审计；同键异文拒绝，同键同文恢复原结果。照片正文按 owner、用途、版本、长度、类型与摘要读取，不暴露任意路径读取。
- 名册日期为用户显式登记日期，实际归档时间取服务端；历史缺资料仍登记缺口。当前项目与进退场日期不能自动证明过去月份的在场状态。
- 受控迁移保留原值、软删除、原件正文及映射；未知用途不自动变成两类照片。新增归档引用纳入危险回滚保护。
- 页面采用整页工人资料与独立归档工作区；下载使用现有 XLSX/ZIP 底座，文档交付 Markdown。

## Testing Decisions / Acceptance criteria

- [x] 公开服务先复现无私密权限不可读取及照片/归档尚未接通，再验证维护、归档、冷读、下载完整纵切。
- [x] 同名异 ID、负责人/零分配/离职/转组、缺日期、缺正文、无劳动合同事实分别保真。
- [x] 跨项目、跨来源、错 owner、任意额外工人、撤权、会话变化和迟到响应拒绝；列表/详情保持脱敏，错误及日志不泄露私密正文。
- [x] 来源陈旧、双窗口、同键异文、失响应重试和任何写入失败均不留下半份归档或丢失原稿。
- [x] 归档后改工人资料、照片和当前归属，旧工资、旧名册和原件字节/摘要不变；新版本带独立日期。
- [x] 真实 SQLite 受控迁入完整字段/原件并核对缺口；重复确认保日常版本，相关回滚整批拒绝，无关资料不误阻。
- [x] 实际浏览器维护→工资成员预览→归档→冷刷新→下载→补充新版本通过；五档视口、表内滚动、焦点与返回保护通过。
- [x] 实际 XLSX/ZIP 回读核对成员、版本、日期、字段、照片路径/摘要，不能只验证生成器被调用。
- [x] 权威数据/命令/读取/页面与 Markdown 指南一致；类型、规范、定向及全量测试和独立 Standards/Spec 复核通过。

## Blocked by

无新增阻塞，可开始。已具备中央工人身份、已发工资完整冻结读取、工作区事务及受控迁移框架。正式编号和其他工作簿修复不阻塞本票独立名册归档与下载；最终组合输出由根任务整合。

## Out of Scope

正式编号、资金建议/尾差、月对账、完整账号/RBAC、自动识别照片用途、任意外部文件读取、生产持久化/部署及 B 新工资。不得以本票完成关闭 #412/#407/#406 全模块。
