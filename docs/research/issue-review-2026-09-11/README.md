## 更新方式

维护同目录 `rows-*.json` 的事实判断；以新抓取的 `gh issue list --state open --json number,title,body,comments,labels,url,updatedAt` 结果调用 `build_report.py --issues <快照路径>`。生成器检查 Issue 全覆盖、唯一编号、异常回路索引与证据真实路径，不把源码检查当作业务验收。
