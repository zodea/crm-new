# 域文档使用规则

## 消费顺序

按问题直接读对应章节，无须依次通读：

| 问题 | 现行来源 |
| --- | --- |
| 业务术语、关系与易混区别 | [CONTEXT.md](../../CONTEXT.md) |
| 已采纳的决策、理由与替代关系 | [ADR](../adr/README.md) |
| 实体、字段、关系、索引与迁移 | [DATABASE.md](../rewrite/DATABASE.md) |
| 页面交互、校验与验收 | [页面蓝本](../rewrite/pages/) |

业务实体、类型和测试命名使用 `CONTEXT.md` 中对应概念；普通叙述可使用含义准确的自然表达。

## 维护边界

- 词表只接收已确认的稳定词义，实现状态和候选词不写成定义。
- ADR 记录已经采纳的取舍；新代码不能自行推翻既有决策。
- 研究观察标为非权威；事实核查、法律适用性、冲突裁定与变更授权遵守 [AGENTS.md](../../AGENTS.md#开工与决策)。
