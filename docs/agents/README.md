# Agent 协作入口

本目录只说明如何在本仓库协作，不重复产品和架构规格。

## 开工顺序

1. 读根目录 [`AGENTS.md`](../../AGENTS.md)。
2. 查 GitHub 当前 open Issue；已有定稿规格就直接按它执行。
3. 读与任务相关的 [`CONTEXT.md`](../../CONTEXT.md)、[`docs/adr/`](../adr/) 和页面/数据权威源。
4. 核对工作树，保护其他会话尚未提交的改动。
5. 实现、按风险验证、同步文档、只提交本任务文件。

## 专题

- [`issue-tracker.md`](./issue-tracker.md)：Issue 的查询、创建、更新和关闭。
- [`triage-labels.md`](./triage-labels.md)：分诊状态、类别和附加标签。
- [`domain.md`](./domain.md)：如何消费和维护术语、ADR 与数据模型。
- [`skills-cheatsheet.md`](./skills-cheatsheet.md)：本仓库稳定的技能路由原则；不再维护易失效的全局技能全集。
