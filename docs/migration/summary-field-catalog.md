# 汇总表完整字段字典与系统口径

> 目的：覆盖“汇总表”中除纯明细行外的全部业务字段，明确当前值、系统来源和可用状态。系统不得从本表导入静态总额。

状态说明：

- `可迁移`：有明确源实体或可追溯公式；
- `待补录`：业务含义明确，但资料未提供；
- `需对账`：显示值存在，明细或其他区域与其冲突；
- `旧静态值`：无公式或来源不可追溯，只留迁移报告；
- `暂不统计`：本期明确不做；
- `待定义`：业务公式尚未确认。
