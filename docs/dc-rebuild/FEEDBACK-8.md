# 反馈轮 8 — 全站界面整改清单（2026-07-03）

> 来源：用户逐页走查反馈（九大块）。流程：本文档先行 → commit 留底 → 逐界面实现，**每完成一个界面在本表把状态改为「暂定界面」**（暂定 = 已按本轮要求实现、待用户过目定稿）。
> 全局铁律（本轮新增，后续所有界面遵守）：
> 1. **表格三件套**：所有 table 默认铺满可用高度或至少 10 行展示高度；**横向滚动只发生在表格容器内**（禁止把整页撑出横滚）；必须有分页条。（本轮成文，已收编 [ADR 0009](../adr/0009-vxe-table-as-datagrid-engine.md)，阈值以其为准。）
> 2. **金额精确到两位小数**：经营数据/票据信息等一切金额不许省略号缩略（这是 CRM，看数是第一目的）；「万」缩写仅限甘特/图表角标。
> 3. **参考红圈**：列表列数、编辑表单字段数向红圈系统截图对齐（`红圈系统/` 各模块 md + png），不做「三五个字段的玩具表单」。

## 全局修复（本轮附带）
- **整页横滚根因修复**（app.dc.html）：内容列 flex 项缺 `min-width:0`，深层表格 `min-width` 的 min-content 会穿透滚动容器把整页撑宽——补上后**任何页面**的宽表都只在表格容器内横滚（验证：分供方页 scrollW=docW，表格容器 scrollWidth>clientWidth）。
- **KitTable 全局表格原语**（kit/KitTable.jsx，隐藏预载）：三件套统一载体（阈值/金额格式见 [ADR 0009](../adr/0009-vxe-table-as-datagrid-engine.md)）；ProjectScreen / SupplierScreen / 项目详情 SubTable 已接入，后续列表页一律用它。
- data.js 项目扩充至 12 个（红圈式列表需要分页与滚动的真实体量）。

## 分界面定界

### 一、首页
- **1 成本对比条**：底部「项目级成本对比（目标/已发生/按进度应耗）」计算口径看不懂、用处不大 → **删除**；成本对比的正确位置是**工程量清单**（合同单价×量 vs 班组单价×量 = 毛利，三量口径可选）。
- **2 底部模块**：甘特下方其余卡片（意义不明的汇总块）→ **删除**，这些内容在项目详情页查看即可。首页只留：项目 Tab + 统一施工进度甘特 + 图例。

### 二、施工项目
- **1 项目列表**（参考红圈 03-项目信息 列表页）：列补全为 红圈式多列（项目编号/项目名称/客户/项目经理/经营类型/工程地域/合同金额/已收款/状态/计划开工/计划竣工/操作…），表格容器内横滚 + 分页 + ≥10 行高度。
- **2 项目编辑**：新建/编辑弹窗对齐红圈新建表单（基础信息分组：名称/编号/客户/客户2/经营类型/地域/详细地址/经理/计划开工/计划竣工/工期/概况/备注…），两列布局分组表单。
- **3 阶段时间线**：横向压缩胶囊改为**通栏大时间带**（每阶段有足够宽度放「上传/查看/说明」操作）；修改动作统一收进「编辑」按钮（模块级大编辑），前台只做展示+编辑弹窗（正式后台再接权限）。
- **4 金额两位小数**：`yuan()`/Metric 全部改为 `#,##0.00` 完整展示，去掉 `…` 缩略；卡片宽度按数字自适应。
- **5 其余子表**：SubTable 统一表格三件套 + 红圈式列头。

### 三、施工进度
