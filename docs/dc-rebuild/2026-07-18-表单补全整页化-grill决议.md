# 表单补全·整页化 grill 决议（2026-07-18）

> `/grill-me` 会话定稿。背景：用户反馈「设计稿很多新增、修改界面不够齐全，填写的内容很少」。
> 本轮**只改设计稿**（`DC重构设计源码/`，DesignSync 推 claude.ai/design 项目），**不改 Vue 项目代码**。
> 对标依据：[红圈补采差距清单 §1/§2/§6](./2026-07-11-红圈补采差距清单.md) + 红圈截图实拍（付款申请/支出合同/收票登记/分供方 表单逐字段提取）+ `docs/pages/*.md` 字段规格。
> 2026-07-18 补充：下述宽度与列数只表示宽屏目标，所有表单必须遵循 [ADR 0013 响应式与自适应契约](../adr/0013-align-all-ui-to-online-design.md)，不得实现成固定长宽画布。

## 决议清单（9 问）

| # | 议题 | 决议 |
|---|---|---|
| 1 | 大单据表单容器 | ~~宽弹窗~~ → **整页表单**（问2 扩大范围后此问并入） |
| 2 | 整页表单覆盖范围 | **全部实体一律先做整页表单**，后续需要优化的再退回弹窗。发票编辑沿用既有 InvoiceEditScreen 整页 |
| 3 | 整页表单挂法 | **B：每实体独立表单路由、新开页签**（红圈式）。表单规格按域分文件放 `kit/forms/`，壳里一个统一分发入口（`isEntityForm` → EntityFormScreen 按 route 查 `window.KIT_FORM_SPECS` 注册表），PAGE 表补页签标题。formModal 控件层抽成 `buildFormBody` 复用，整页/弹窗共用一套字段渲染 |
| 4 | 字段规模取舍 | 业务字段**照红圈全量补**（支出合同 33 头字段、付款申请 45、分供方 29 量级）；**附件位保留**（`type:"file"` mock 控件：虚线框「拖拽或点击上传 (0/15)」）；**系统信息组砍**（等真实后端）；地图定位砍 |
| 5 | 明细网格范围 | 材采合同（10 列精选+导入明细按钮）、付款申请（关联结算+关联发票）、甲方变洽签（变更行）、甲方报量（报量行）、库存盘点、材料到货。施工/分包合同不加（清单走拆表链路）。红圈 21 列中依赖跨单据聚合的 6 个只读勾稽列不摆空架子。**EXCEL 粘贴模式（TSV 解析批量插行）和全屏编辑要做**——快捷录入刚需 |
| 6 | 类型选择三段式 | **付款申请**：typeSelect 8 类型 → 整页表单按类型显隐分区（替换现有宫格 addFlow）。**分供方**：typeSelect 用本项目七类 **材料供应商/劳务分包商/专业分包商/设备供应商/检测供应商/个人/其他**（不抄红圈大宗/房东那套）。其余实体不做三段式（kind 由路由已分流；变更 4 类保持表单内 select） |
| 7 | 编辑回显 | **B：精选回填**——表单铺完后串行补 data.js：每个重点实体 1~2 行代表性假数据填新字段（合同×3kind、付款申请、分供方各 2 行；收款/开票/变更/到货/盘点各 1 行）。**从 data.local.js（车陂真实数据，gitignored）提炼量级和写法风格，值全部匿名虚构**；data.local.js 本体绝不动、绝不上传 |
| 8 | 整页表单版式 | 宽屏左锚点用 `clamp()` / `minmax()` 设有界宽度并 sticky（<3 分区或容器不足时隐藏/转顶部选择器）+ 每 section 一张圆角卡片（ADR 0007）+ 字段最多两列、按最小可读宽度自动单列 + 底部吸底动作条（窄屏可换行且主动作可达）+ 内容区 `max-width:1080px` 仅作上限、宽度流式填满 + 面包屑「← 返回列表」。编辑同页标题「编辑 · xxx」，页签按 id 去重 |
| 8b | 底部五按钮语义 | 取消（dirty→放弃确认）/ 保存草稿（**跳必填校验**、dirty 前置灰、statusKey 写「草稿」）/ 保存并新建（存完再开空表单）/ 保存并提交（statusKey 写「审批中」）/ 保存（主色）。左下「【保存】后关闭」勾选（默认勾，不勾=保存后留页继续编辑）。审批流节点图/时间线不在本轮（差距清单 §5 另课题） |
| 8c | 草稿三入口 | ①列表状态列灰「草稿」徽标（与审批徽标同体系）②视图行固定「草稿 N」chip（0 条也显示）③草稿行整行点击直接进整页表单续填（普通行点击进详情） |
| 8d | 页签切换保值 | **硬性要求**：表单页签切走再切回，填写内容（含明细网格行）按页签缓存原样恢复；仅关闭页签弹「放弃修改?」拦截 |
| 9 | 落盘与推送 | 分批提交（底座 / 各域规格 / data.js 回填 / 文档 各一笔）；全部验证通过后 DesignSync 一次性推送（data.local.js 永不上传）；Vue 项目 `app/` 零改动 |

## 底座契约速查

- `KitUI.formModal` / `buildFormBody` 字段契约：`section` 分组 / `required` 双通道校验 / `hint` / `suffix` / `type:"lookup"`（检索下拉+级联 `dependsOn`）/ `type:"readonly"`+`compute`（带出区块，默认不回写 store）/ `type:"grid"`（明细网格+derive+Σ+EXCEL粘贴+全屏）/ `type:"file"`（附件位 mock）。
- `EntityListScreen` meta 扩展：`formOnly`（仅表单字段，不占表格列）、`formRoute`（整页表单路由）、`formWidth/formCols/formActions`、`statusKey`（草稿/提交状态落点）。
- 表单规格注册：`kit/forms/*.jsx` 按域分文件 → `window.KIT_FORM_SPECS[route] = (params) => spec`。
