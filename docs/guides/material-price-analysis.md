## 一、实现进度

本说明只展示当前已可使用的材料单价分析流程。

浏览器单价分析与送货归档读取同一份已保存记录，项目、分供方及材料采购合同一起核对后才显示完整送货分析。正式来源读取失败或权限失效时撤下旧分析并提供重试；旧本地适配在身份、权限及来源不变时可显示上次送货分析，并提示仅供查看，不能作为当前比较或导出依据。具体边界直接见 [READ-MODELS 刷新规则](../rewrite/READ-MODELS.md#permissions-and-stale-data)。不会用同名本机记录或演示价格代替；真实来源和测试数据分别呈现。旧本机记录需先完成相应受控迁移。

> 送货分析区域只分析已归档、已完成人工核对且当前单价有效的送货单明细。缺单价或金额的送货事实可以先归档，但会标记“价格待补录”，补录并人工确认有效单价前不会进入送货分析；合同约定价按独立原行读取，操作见第六节。

> 官方价格只按已核实的材料编码、型号、芯数、截面和单位关联。当前仅 BV 1×2.5 mm²、单位为米的规范身份有官方价格事实；其他材料不会因名称或分类相似而自动套价。

## 三、价格视图规则

### 3.1 人工确认门禁

- OCR 识别出的单价只是候选值，不会自动成为价格分析事实。
- 送货单必须已归档并完成人工核对；存在未复核、自然键重复或当前值未确认状态时不进入分析。
- 缺原件的记录保持缺失提示，不因已填写有效价格而进入分析；补齐可信原件并核对后再查看。
- 单价必须是人工确认后的有效正数。单价为空、非数值、零或负数的材料行均不进入价格趋势和厂家对比。
- 缺单价或金额时，可在查看原件并确认送货事实后先归档为“价格待补录”；后续补录有效单价并保存确认后，才获得价格分析资格。
- 运费、搬运费等非材料费用行不进入材料单价分析。

### 3.2 电线身份规范化

- BV 支持全称和简称；规格可写在材料名称或规格栏。
- `2.5`、`2.5mm2`、`1×2.5`、`1*2.5` 统一为 `1×2.5 mm²`。
- BVR、YJV 会形成各自稳定身份，不与同截面的 BV 合并。
- 只处理精确的 BV、BVR、YJV 基础型号和单一截面规格。`ZR-BV`、`NH-BV`、`YJV22` 等型号变体，以及 `4×25+1×16` 等复合规格，保留为独立材料，不并入基础型号或套用普通 BV 官方价格。
- 搜索 `2.5mm2` 或 `1×2.5 mm²` 都能命中规范化后的同一材料。
- `米` 与 `m` 统一为 `m`，`千米` 与 `km` 统一为 `km`。两个量级不会互相合并，系统也不会改写送货单市场单价。

### 3.3 价格趋势

同一厂家对所选材料存在多个日期价格时，页面展示时间趋势：

- 最多同时查看 4 家厂家。
- 图中每个点对应一张已归档送货单。
- 可在图下“全部价格来源”中打开对应送货单详情。

### 3.4 厂家最新价对比

每家厂家只有一个有效价格时，页面展示横向比较：

- 每家取最新日期的有效价格。
- 显示最低价、中位价、最高与最低的价差。
- 每行保留价格日期、项目和来源送货单。

## 四、厂家合作合同

页面底部按“厂家 + 项目”汇总材料采购合同，显示：

- 合同数量和合同名称。
- 合同金额合计。
- 签订日期。
- 合同详情入口。

该区域是所选送货材料出现厂家的合作历史，可能包含其他材料采购合同，不表示这些合同购买过当前材料，也不作为当前材料正式采购家数。当前材料真实合同约定行另在页面上方按原行 ID 展示。该区域只读，不会修改合同或送货单。

## 五、广州官方信息价

- 当前已接入“铜芯聚氯乙烯绝缘电线 BV 1×2.5 mm²”，材料编码 `280304800070120011`。
- 页面展示 2026 年 2–6 月官方月度价格，原单位为千米，系统统一换算为元/米。
- 选择该材料后，趋势图同时展示官方价格和厂家实际价，并显示最新官方价环比涨跌，以及官方价与市场中位价的差额、比例。
- 每个月份保留广州造价站原始 PDF 链接；信息价是市场综合参考，不代替合同、品牌和票据核对。
- BVR、YJV、BV 其他芯数/截面以及千米口径市场价不会套用该官方价格。

## 六、合同约定价与单位比较

页面上方独立展示有效材采合同及补充协议明细，按材料、规格、材质筛选，点击合同回看原单；名称相同不自动证明同材质、同税费或同运费条件。税点只读取已核实适用于本行的值，未记录显示 —，明确 0 显示 0%。字段及事实归属直达 [DATABASE 材采价格来源](../rewrite/DATABASE.md#material-price-sources)。

展开“按明确依据换算比较单位”，选择原明细，再填写比较单位、正倍数和核实依据。三项齐全后显示本次比较单价；缺少可靠依据继续按原单位查看。该操作只改变比较显示，刷新后清空，不修改原合同的数量、单位、单价或历史。公式和适用边界只在 [DATABASE 单位换算](../rewrite/DATABASE.md#contract-price-unit-conversion) 维护。税费、运费条件未齐时不能从两行价格宣称同条件到货成本或最低价。

## 七、独立报价与来源迁入

在“乙供材管理 → 独立报价”打开清单，选择“新增报价”。按原件填写报价方原文、真实适用范围和材料行，再选择需要同时保存的原件。未建档报价方可以直接保存；只有已核验时才明确选择目录中的分供方或项目。空值的含义和报价关系例外直接见 [DATABASE 独立报价](../rewrite/DATABASE.md#quotation-target)，页面不会因名称相同自动建立关系。

保存后打开详情，通过“查看冻结版本”回看原价、原条件和该版本原件。提交期间增加的输入或原件按[同目标后读规则](../rewrite/COMMANDS.md#success-receipt-and-readback)留在当前页继续核对，再次保存更新已保存的同一报价。修订形成新版本，历史链接始终包含原报价 ID、原行 ID 和版本。遇到“核对原提交”时，使用该入口恢复原命令，确认前不要另建报价；保存已完成但读回失败时也沿同一入口。发生版本冲突时先核对最新资料，再明确采用最新版本继续保存，当前输入保留。

“单价对比”中的综合原价区列出实际可读取的三类来源。选择一行，明确比较单位、换算依据及基准原行，再核对材料依据；结果只改变本次显示。项目筛选包含通用报价和该项目的真实关联报价，范围未知资料保持独立。分供方筛选按稳定 ID，未关联报价方不会被同名目录覆盖。真实零价在报价原价中显示零；未知单价保持未知。原送货趋势仍采用第三节的有效正价样本，不把零价改造成市场趋势点。

切换到测试来源、离开该页或权限失效后，旧独立报价立即撤下，不把真实报价混入测试分析。回到真实来源时重新读取；合同、报价或送货的缺源提示各自保留，不以另一来源补齐。

如果旧本地库已有报价，先准备旧桌面版留下的完整一致快照（见[本地数据迁移指南](./local-data-migration.md)），再在正式浏览器工作区从报价清单进入“报价来源迁入”，选择该完整 SQLite 快照，核对原身份、冻结版本、原件及完整图摘要。原项目和分供方逐条选择真实目标记录，再勾选已核对对应关系；名称相同不自动选中。目标版本变化时重新读取目录并确认，不能省略未知关系。迁入后详情同时保留原编号和已确认当前关联，后续编辑采用当前关联，原冻结历史继续按原文回看。结果未知或读回失败时核对原迁入编号，实际核验完成后再运行本地数据迁移预检；已有中央报价时拒绝覆盖，原库、原件和备份继续保留。平台切换不会仅凭迁移版本号丢弃报价。当前 Native 新报价写入仍受可信本地操作者绑定限制，详见[页面实现边界](../rewrite/pages/material-management.md#三材料单价分析)。
