> 本文只说明当前已经可以实际操作的流程。

## 工资

1. 打开“分包及人工 → 工资核算”。
2. 选择项目、月份和班组，点“生成月度草稿”，再选择负责人和同班组成员。A 户型派生可选月度/结算/尾款；C1 月薪时工和 C2 零星签工只开放月度档。B 标记为后续，当前不可选择。
3. 月度进度可选暂估量或现场复核量；结算档固定按现场复核量的 95%，尾款档固定按现场复核量的 100%。合同量不会作为工资取数。
4. A 在草稿明细录入工资单价；现场量核对只计入已完成工序，不能把已指派但未施工的户计入工资。C1 先维护工人档案日薪并在考勤页录入日工和加班。C2 先在“录入 C2 签工”维护逐日记录，再按已确认工数和请款主体大工单价生成工资行。
5. 应发金额显示“当前累计应付－同负责人同格式此前已发累计”，本次金额为 0 不能发放。
6. 点“核对并锁定现场量”，系统保存现场量/考勤来源版本。缺量会明确报错；核对后若上游变化，发放会被拦截并持久标记为“需重核”。
7. 填写不超过本次应发的实际金额和必要的调账原因后点“确认已发放”。系统在发放事务内再次扣减此前已发；应发为 0 时不能绕过。已发放快照保留项目/班组/负责人、来源时间/版本、累计应付、此前已发、成员、明细、操作者和提交时间，后续改名、改量、改价不追溯。

## 考勤

1. 从工资页点“打开考勤”，或打开“考勤管理”。
2. 选择项目、月份、班组。
3. 点击工人对应日期，填写正常工时、加班工时和施工内容后保存；正常与加班合计不得超过 24 小时。
4. 从全部班组视图录入时自动采用工人档案中的班组；C2 签工人员不可录考勤。
5. 同一天再次保存会更新原记录；矩阵横向滚动时工人姓名列保持固定。
6. C1 当月工资发放后，该请款簿负责人和成员的当月考勤锁定；需要先确认考勤完整再发放。

## C2 零星签工

1. 从工资页点“录入 C2 签工”。
2. 选择项目、月份、班组，填写日期、人员、施工内容、起止时间和整工 1 / 半工 0.5。
3. 有证明人和确认日期时保存为“已确认”；资料未齐可保存为“待确认”，但不会计薪。资料补齐后在记录行点“编辑”，改为“已确认”并保存。
4. 返回工资页，格式族选择 C2；大工单价和确认规则按项目×负责人保存并在下次建单时复用。
5. C2 固定按已确认签工 100% 核算，不生成考勤表；同一人员同月已有考勤时不能再录签工，反向也相同。同一人员同日签工不能重叠且合计不超过 1 工。
