## 二、查找和查看分供方

1. 进入“基础信息 → 分供方”。
2. 在搜索框输入公司名、简称、统一社会信用代码或联系人。
3. 点击表头漏斗筛选单列，或用搜索右侧“筛选”“排序”工具缩小结果；分页由中央端完成。
4. 点击分供方名称，或在行尾省略号菜单选择“查看详情”。编辑仍需从详情显式进入。
5. 顶栏测试数据关闭时只显示正式分供方；显式开启且具有权限时才显示测试分供方。

列表采用单行紧凑工具栏，类别与资料状态收进筛选浮层，条数与分页位于表尾。窄屏时工具按顺序换行；宽表在自己的区域横向滚动。

没有指定业务页签时，详情默认显示“详细资料”，依次呈现“基础信息”“联系人信息”“开票信息”，开户行和银行账号归入开票信息。切换“合作项目”“支出合同”“支出结算”“收票登记”或“付款管理”后，主区域直接显示对应事实表，不再在表格前重复完整资料。顶部保留公司名称、简要联系资料、来源标识和已有操作。

统一社会信用代码、内部编码、银行账号和联系电话按 capability 遮罩。测试详情带“测试数据”标识且没有编辑入口；受限关系显示“无权限”，缺失关系显示“未记录”，两者都不会生成死链。

也可以从项目详情进入材料采购合同列表，再从合同详情选择“合同事实、结算事实、收票事实、付款事实”。系统使用合同中的分供方稳定 ID 和同一数据来源打开本页，并直接定位对应事实页签；刷新页面仍保留当前页签。点击“返回材料采购合同”会回到原合同及原合同页签，不会落入分供方列表或本地写态。

## 三、理解摘要和四类真实事实

“往期合作情况”位于宽屏详情右侧，展示合作项目、累计合同金额、累计结算金额、累计收票金额、累计付款金额和应付金额；其下是档案信息。空间不足时，这些辅助内容移到主区域下方。

具备明细查看能力时，前五项显示为蓝色入口，即使金额为 0 也可进入对应事实页签。点击后，页面会滚动到页签导航，并将键盘焦点移到选中的页签，窄屏下也能立即看到目标内容。应付金额只展示，不可点击；没有查看能力的金额不生成入口。

| 事实 | 当前来源 | 进入目标 |
| --- | --- | --- |
| 合同 | supplier_id 指向当前分供方的有效合同，加有效补充协议 | 合同详情；项目关系可用时进入项目详情 |
| 结算 | 已登记且状态确认的支出结算 | 进入结算事实页签；没有 canonical 详情路由的行保持普通文本 |
| 收票 | supplier_id 指向当前分供方且已归档的发票 | 发票详情；未归档发票不计入金额 |
| 付款 | 已确认支付记录对当前分供方付款申请的实际分摊 | 付款申请只读详情；不把申请金额当成实付 |

应付金额等于有效合同金额减确认实付，仅用于摘要。它不是一张源单，因此不会伪装成蓝色入口。真实事实暂时为 0 时，页签显示“暂无……事实”，这表示当前没有记录，不表示服务失败。

## 四、新建和显式编辑正式分供方

### 新建

1. 在列表点击“新增分供方”，先选择分供方类别。
2. 填写公司全称、分供方类别和主要联系人；这三项在正式保存时必填。
3. 按需填写简称、税号、法定代表人、开票资料、银行资料和联系方式。
4. 点击“保存”。中央后台生成正式分供方 ID，页面进入新详情。

### 编辑

1. 从列表进入正式分供方详情。
2. 点击顶部“编辑”，在独立整页表单修改主档。
3. 保存成功后回到同一详情；刷新页面确认中央读回结果。
4. 若其他操作已先更新该分供方，系统阻止旧版本覆盖，可保留当前内容并基于最新版本重试，或改用服务器最新版。

统一社会信用代码或内部编码重复时，中央端返回字段错误。中央服务不可用时不会伪装保存成功。证照原件、OCR 和人工资料核验从详情顶部“证照附件”进入独立专用页面，不作为本次主档命令的普通附件。浏览器中的正式中央分供方会明确提示专用存储尚未接入，绝不读取或写入旧本地证照库；只有从顶栏显式开启并通过权限核验后，测试分供方才展示经中央身份核验的纯读证照快照。Tauri 桌面端的正式本地身份仍可使用原有证照维护流程。

## 五、返回原列表

从列表进入详情时，地址保存当前搜索、类别、资料状态、排序、页码、每页条数和原行锚点。继续进入编辑并保存后，点击“返回分供方列表”仍恢复这些状态，并把键盘焦点放回原分供方行。

从材料采购合同进入时，返回目标改为原材料采购合同；合同自身继续保留材采列表和项目详情的返回上下文。因此可沿“分供方事实 → 合同 → 材采列表 → 项目详情 → 项目列表”逐级返回，并恢复各层筛选、页签、滚动和焦点。

外部地址、异常返回地址或不属于 `/base/supplier` 的目标会被拒绝，系统回到规范分供方列表。不要手工修改详情地址中的 `origin`；ID 与来源不一致时会显示来源错配。

## 六、当前边界

### 当前已可用

- 浏览器正式分供方中央新建、编辑、幂等命令、版本冲突和保存后读回。
- 正式与测试来源隔离，测试分供方只读，敏感字段按 capability 遮罩。
- 默认资料页签、三个资料分区、独立业务事实表及随容器宽度调整位置的往期合作和档案辅助区。
- 合作项目及合同、结算、归档发票、确认付款四类真实事实。
- 从材料采购合同按稳定分供方 ID 直达四类事实，并安全返回原合同页签。
- 0 事实、缺失关系、无权限关系、来源错配、记录不存在和中央服务错误的独立状态。
- 证照专用地址完整保留来源与列表返回上下文；正式浏览器身份不可落入旧本地可写链，测试身份只读。

### 已定稿待开发

- 正式登录、完整 RBAC 和生产持久化后台；当前中央端是可重置的非生产证明实例。
- 分供方中央删除、软删除恢复及下游影响确认。
- 没有 canonical 只读详情路由的结算行目标；当前保持不可导航，不链接到编辑表单。
- 证照文件、OCR 与人工核验的中央化；当前完整可写专用流程只属于 Tauri 正式本地身份，浏览器正式中央身份保持明确不可用。

## 七、完整列表、表头查询与劳务承包范围

本节介绍2026-09-08接入的实际界面能力。中央浏览器实例的生产持久化边界仍按第六节说明；界面可操作不代表已经完成生产部署。

### 列表内容和状态标签

默认列表完整展示适用于瑞航的业务列，并按资料、联系、业务范围、银行信息和合作金额分组。默认每页20条；表格过宽时在内部横向滚动，宽屏保留名称和行尾操作。窄屏释放左侧固定列，避免遮住后续内容。

页面只保留少量必要文字，低频字段解释放在就近帮助提示中；错误和关键状态仍直接显示。

| 内容 | 使用方式 |
| --- | --- |
| 分供方资料列 | 显示唯一识别码、注册地址、纳税人类型、主营业务、劳务承包范围、开户行、银行账号和经营类型；唯一识别码与统一社会信用代码分开，银行账号继续按权限遮罩 |
| 金额与合作列 | 保留累计结算金额、累计合同金额及瑞航已有的有效合同额、确认实付、合作项目数等各自口径；不把不同含义的金额换标题当作同一项 |
| 名称和资料状态 | 名称链接进入真实详情，长名称可以查看完整内容；资料缺失、齐全待核验、合格、退回用统一的文字和紧凑标签区分 |
| 营业执照 | 只有接通真实证照资料后才显示可用文件或资料状态；尚未接入与确实缺失分开说明 |

资料状态表示资料完整性与人工核验结论。列表和详情统一显示“资料缺失”“齐全待核验”“合格”“退回”，未知值使用中性提示。核验结论仍由证照与人工核验规则产生；不会照抄参考系统的“已通过”。上级供应商与参考审批流程不属于本次新增内容。

### 表头、搜索和右侧工具

点击表头漏斗可填写“包含关键词”、选择类别/状态或设置金额区间；支持排序的列还显示升降序操作。点击“应用”后，条件作用于完整允许范围，再排序、分页；改变条件回到第1页。每列可单独清除，也可在工具栏“筛选”中清除全部条件。

搜索会联动表格与总数，包含新增的劳务承包范围。表头条件可与搜索叠加；银行账号、信用代码等仅按有权限看到的内容查找。刷新按钮保留当前条件，详情返回恢复原查询和行焦点。

| 工具 | 当前使用方式 |
| --- | --- |
| 刷新、新建 | 当前已有；刷新继续读取当前条件，新建继续先选类别，再进入整页表单 |
| 排序、筛选 | 排序工具可选择名称、类别或金额/项目数次序；筛选工具提供类别、资料状态和清除全部条件 |
| 列设置 | 勾选要显示的列，可切换舒适行高；“恢复默认”显示全部适用列并恢复紧凑行高。视图偏好保存在当前浏览器 |
| 导入 | 选择文件、核对字段映射与预览后开始导入；结果写入当前列表使用的资料库，按外部旧ID更新匹配记录，未映射字段保留 |
| 导出 | 列表导出台账和分类导出仍待接通，当前不能按旧工具栏截图判断已经可用 |

导入时“唯一识别码”映射内部编码，“统一社会信用代码”映射信用代码；两者不能混用。没有外部旧ID时按新记录校验，重复内部编码或信用代码会给出失败反馈。资料状态不接受导入文件伪造人工合格。

### 独立填写劳务承包范围

“劳务承包范围”描述可承接的工种或作业范围，例如“石材安装、楼梯铺贴”。它是独立的可选自由文本，与“主营业务”分别维护；所有类别均可留空，不自动复制主营业务，也不强制选择工种分类。

新增或编辑分供方时，在主营业务之后填写、修改或清空该项。保存后，列表、详细资料和再次打开的编辑表单展示同一内容，并可用关键词或独立列条件查找。旧档案默认留空。

填写或修改劳务承包范围不会改变资料齐全度、已有人工核验结论或准入要求，也不代表取得某项资质。纳税人类型旁的问号可悬停、键盘聚焦或点击查看说明，按Esc关闭后可继续填写；实际校验错误仍直接显示在字段旁。
