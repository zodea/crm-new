## 二、从项目详情进入工作台

1. 打开“项目信息 → 项目列表”。
2. 点击项目名称进入项目详情。
3. 在右侧“项目分供方”区域选择一家分供方。
4. 系统打开当前项目和该分供方的合作工作台。

工作台顶部显示项目名、分供方名、合作状态，以及合同、请款、收票、已付和应付余额等真实摘要。点击返回按钮可回到项目详情；合作概览中的项目名和分供方名可以打开对应详情。

工作台不会把未加载的数据伪装为零。读取中、没有记录或读取失败时，会分别显示对应状态和重试入口。

## 三、查看业务页签

### 合作概览

合作概览集中显示：

- 当前项目及项目状态。
- 分供方类别、联系人和联系方式。
- ProjectSupplier 合作状态。
- 当前合作关系的金额摘要。

### 合同

合同页签显示当前项目与分供方之间的支出合同，包括原合同额、补充协议后的有效合同额、状态、签订日期和附件数。点击“查看源单”进入合同详情。

### 请款

请款页签显示付款申请单号、申请金额、批复金额、审批状态、申请日期和回票类型。点击“查看源单”进入付款申请。

### 收票

收票页签显示发票号码、日期、发票类型、含税金额、税额和归档状态。只有已归档发票计入顶部收票汇总。点击“查看源单”进入发票详情。

### 付款

付款页签只使用经过人工确认的支付事实。金额按支付记录分摊到当前项目和分供方付款申请的部分计算，不会把一张涉及多份申请的银行回单重复计入。点击“查看源单”进入支付记录。

### 结算

结算页签分为两个区域：

- **支出结算单**：合同过程或完工结算，是付款申请可以关联的真实依据。
- **合作终态结算确认**：只用于最终关闭当前项目×分供方合作关系。

二者不会混成同一笔结算，也不会互相替代。

## 四、追溯和使用合作文件

工作台下方“合作文件”按真实来源分组，例如：

- 合作档案。
- 合同。
- 付款申请。
- 发票原件。
- 支付记录。
- 支出结算。
- 最终结算。

每份文件显示名称、类别、大小、上传人和时间。点击“预览”在应用内读取文件，点击“下载”保存副本；有真实源单的分组还可以点击“查看来源”进入对应业务记录。

预览、下载和查看来源都是只读操作，不会改变合作状态或源单数据。

## 五、从文件导入分供方

### 第一步：选择文件

1. 在项目详情右侧点击“从文件导入分供方”。
2. 将多个文件拖入选择区，或点击“选择文件”。
3. 需要一次处理整个目录时，点击“选择文件夹”。
4. 核对文件名、相对路径、大小和类型。
5. 移除不需要处理的文件，然后点击“下一步：自动分类”。

文件在最终确认前不会写入数据库。

### 第二步：分类与调整

系统只在本机根据文件名执行初步分类：

- 用现有分供方公司全称或别名匹配分供方。
- 用“合同、请款、发票、回单、结算、资质”等关键词判断文件类别。
- 未匹配的文件生成一个待确认的候选分供方名称。

该步骤不读取文件正文、不上传云端，也不执行 OCR。请逐项核对：

1. 从下拉框选择正确的现有分供方，或保留“新分供方”。
2. 调整文件类别。
3. 新分供方可修改拟建名称。
4. 只有确认名称无误后，勾选“写入分供方主数据”。

未匹配文件没有明确确认时，系统不会进入下一步。

新建的最小分供方档案使用“其他”类别和“资料缺失”状态，后续可从分供方详情补充完整资料。导入文件只属于当前项目合作关系，不会成为分供方证照。

### 第三步：确认生成

确认页按分供方分组，清楚标记：

- “复用已有关系”。
- “新建项目关系”。
- “新建主数据”。
- 每个关系下将归档的文件和类别。

核对后点击“确认生成并返回项目”。系统会在一次保存中完成新分供方、项目关系和全部文件；任一项失败时整批不保存。成功后返回当前项目详情。

同一项目已经存在相同分供方关系时，系统只复用该关系并追加文件，不会再创建一条重复关系。

## 六、确认合作终态结算

只有合作状态为“已付款”时才可以确认终态结算。

1. 在工作台打开“结算”页签。
2. 核对支出结算单、请款、收票和付款记录。
3. 填写最终结算金额和结算日期。
4. 选择结算确认书 PDF。
5. 点击“确认结算”，再在二次确认中确认。

最终结算金额、日期和 PDF 缺一不可。确认时系统会在同一次保存中：

- 新增唯一的合作终态结算记录。
- 把 PDF 归档到最终结算。
- 将 ProjectSupplier 状态改为“已结算”。

合作终态结算确认不能重复；合同、付款申请、发票、支付记录和支出结算单仍由各自源模块维护。支出结算单保留在独立区域，供来源追溯。

## 七、窄屏和键盘操作

- 手机上摘要和操作区会自动换行。
- 业务宽表只在表格内部横向滚动，不带动整个页面。
- 文件导入的三个步骤按页面宽度重排。
- 使用键盘 `Tab` 可以依次到达文件选择、移除、分供方、类别、确认框、上一步、下一步和最终确认。
- 下拉框可使用方向键选择，复选框可使用空格切换。
- 二次确认打开后，焦点留在确认区域；关闭后返回原操作按钮。

## 八、使用边界

- 工作台不负责新建或编辑合同、付款申请、发票、支付记录和支出结算单。
- 文件导入不自动生成业务单据。
- 文件名分类只是初步建议，最终以人工调整结果为准。
- 只有已归档发票、已确认支付和有效审批/结算状态进入金额汇总。
- 合作终态结算不参与付款申请的结算分摊。
