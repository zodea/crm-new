# 本机工序库保存与旧版本核对

当前 #463 已接通本机磁盘保存，并在隔离合成工作区验证服务关闭后重新打开。正式业务用途的写入仍等待备份与上线门禁；不要把演示环境或合成验证环境当作实际业务库。配置与登录沿[本机客户指南](./local-customer-storage.md)，部署边界见 [ADR 0021](../adr/0021-single-operator-windows-production-storage.md)。

## 新建和查看

1. 登录本机工作区后，进入“施工进度 → 标准工序库”。新工作区显示真实空库，不自动放入演示工序。
2. 选择新建空白工序库，在整页填写编码、名称、版本说明及工序。具体排序、工期和前置关系操作沿[项目启动与排程指南](./project-start-and-schedule.md)。
3. 点击“保存为新版本”。成功后进入带版本号的只读详情；需要继续调整时，选择“基于此版本新建”。旧版保持原样。
4. 服务关闭重开后需重新登录，再从目录或原详情地址打开。已保存版本的身份、工序定义和时间保持一致。

## 保存结果不确定或出现冲突

- 保存失败时，当前页面保留输入。内容没有改变时再次保存会核对原提交；已经成功的提交返回原版本，不额外增加编号。
- 同编码有其他新版本时，按页面提示重新核对系列，再检查保留的人工稿。不要通过改网址或另造编号绕过冲突。
- 若服务重启需要重新登录，先核对目录与已保存版本。此切片保证服务器原提交可恢复，不承诺关闭浏览器后恢复未提交表单内容。
- 页面提示无权限、数据无法核对或连接不可用时，应保留当前工作并停止保存。系统不会自动换用演示库或另一份本地库。

## 当前边界

本机工序库保存完整不可变工序版本。目录及版本详情显示当前可读项目的真实排程引用数量；没有引用时显示零，权限不足或来源未接时显示“未知”，不表示没有项目使用。项目 WBS 的原库接管沿[项目启动与排程指南](./project-start-and-schedule.md)，备份发布仍单独验收。新增版本不会追溯修改原项目冻结的工序快照。
