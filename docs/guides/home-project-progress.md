## 一、当前已可用

首页用于查看当前项目的施工进度。浏览器中新建并保存的正式项目可以进入首页项目选择器；再次打开首页时，会重新读取项目名称和查看权限。

首页只读，不填写实际进度，不生成收付款、工资或其他经营指标。正式项目的排程与独立施工进度工作区读取同一份中央记录；读取失败或缺少来源时显示具体原因，不能把“排程未知”当成“没有施工”或“完成 0%”。

:::flow
查看|选择首页项目|搜索名称或编号 → 选择项目 → 核对来源与权限
同源只读|打开施工进度|展开楼栋分组 → 查看工序计划、实际进度及偏差
查证|查看工程量|定位当前阶段和楼栋 → 打开户施工详情
返回|回到原工序|返回矩阵 → 返回首页该工序；只读来源页使用“返回首页项目”
维护|独立施工进度工作区|从菜单进入施工进度 → 选择同一正式项目 → 维护计划
:::

## 二、从新项目回到首页

1. 在“全部项目”中新增项目，保存后确认详情显示正确项目名称。
2. 返回首页，打开顶部项目选择器，输入名称或编号查找项目。
3. 点击目标项目，或在搜索后使用键盘选择并按 Enter 确认。
4. 等待读取成功。选择器、页面内容与地址会一起切换到同一项目。

项目较多时，选择器会使用完整目录。正式项目与测试项目按各自来源区分，即使名称或编号相同，也不会借用彼此的排程。

## 三、辨认当前状态

| 提示 | 含义与下一步 |
| --- | --- |
| 排程来源尚未接入 | 当前来源还不能提供排程。点击“查看施工进度来源”查看原因；不把未知显示为完成 0% |
| 还没有施工排程 | 已读取对应项目排程，确实没有楼栋分组；需要建立计划时，从菜单进入独立施工进度工作区 |
| 部分排程数据尚未就绪 | 已有事实继续展示，缺失的工序或工程量会单独提示 |
| 当前无权查看项目施工进度 | 当前权限不足。重新加载可再次核对；页面不会用旧数据补齐 |
| 项目读取失败 | 点击“重新加载”。切换失败时，仍可读的原项目和地址会保留；当前项目已删除、无权或来源关系失效时，旧内容和查看入口会撤下 |
| 尚无可查看项目 | 当前目录没有可查看记录，可前往项目表单建立项目 |

测试数据必须已经授权并明确开启才会显示。测试排程与正式项目无关，不能据此判断正式项目施工情况。

## 四、查看排程与返回

首页的“查看施工进度来源”及“打开施工进度”进入同一项目的只读排程；没有计划、无权和读取失败分别提示。维护计划请从菜单进入“施工进度”并选择项目。

来源页点击“返回首页项目”回到原项目并读取最新名称；项目已删除或权限改变时明确提示，不换成列表中的第一个项目。

展开楼栋分组后，可横滚甘特并点击计量工序下钻矩阵，再打开户施工详情。返回矩阵后，点击“返回首页该工序”回到原工序。有效的项目、来源、分组、任务、阶段、楼栋、月份、视图、工种与责任户条件会保留；失效范围明确提示，不扩大成全项目。

自动进度只统计当前工序阶段及适用楼栋中的应做户；配置负责人不算完成，另一阶段的完成也不会串入。最早完成日成为实际开始日，全部应做户完成后才有实际完成日。手动填报工序只显示只读进度，不提供没有真实来源的完成下钻。

## 五、小屏与键盘操作

在手机等小屏上，项目选择器使用全屏选择面板。搜索后按 Enter 选择；按 Escape 关闭并回到触发按钮。甘特只在自己的区域横向滚动，页面正文无需左右移动。

## 六、适用范围与待开发能力

首页提供同源只读投影，独立施工进度工作区承载建组、调期、依赖、基线及手工进度维护。内部暂估的新增合同绑定仍待后续接通；读取已有绑定记录不表示可以重新绑定。

演示来源须已获授权并明确开启，保持隔离只读；既有桌面本地排程适配继续保留。本指南的浏览器中央验证范围不代表生产服务、重启持久化或备份恢复部署已经完成。
