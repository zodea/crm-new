## 一、当前已可用

首页用于查看当前项目的施工进度。浏览器中新建并保存的正式项目可以进入首页项目选择器；再次打开首页时，会重新读取项目名称和查看权限。

首页只读，不填写实际进度，不生成收付款、工资或其他经营指标。当前浏览器正式项目的施工排程来源仍未接入，因此可以选择项目，但不能把“排程未知”当成“没有施工”或“完成 0%”。

## 二、从新项目回到首页

1. 在“全部项目”中新增项目，保存后确认详情显示正确项目名称。
2. 返回首页，打开顶部项目选择器，输入名称或编号查找项目。
3. 点击目标项目，或在搜索后使用键盘选择并按 Enter 确认。
4. 等待读取成功。选择器、页面内容与地址会一起切换到同一项目。

项目较多时，选择器会使用完整目录。正式项目与测试项目按各自来源区分，即使名称或编号相同，也不会借用彼此的排程。

## 三、辨认当前状态

| 提示 | 含义与下一步 |
| --- | --- |
| 排程来源尚未接入 | 项目资料已读取，但计划和实际进度还无法读取。点击“查看施工进度来源”查看说明 |
| 还没有施工排程 | 已读取对应项目排程，确实没有楼栋分组；当前来源入口仅供只读查看 |
| 部分排程数据尚未就绪 | 已有事实继续展示，缺失的工序或工程量会单独提示 |
| 当前无权查看项目施工进度 | 当前权限不足。重新加载可再次核对；页面不会用旧数据补齐 |
| 项目读取失败 | 点击“重新加载”。切换失败时，已可读的原项目和地址会保留 |
| 尚无可查看项目 | 当前目录没有可查看记录，可前往项目表单建立项目 |

测试数据必须已经授权并明确开启才会显示。测试排程与正式项目无关，不能据此判断正式项目施工情况。

## 四、查看排程与返回

在首页点击“查看施工进度来源”或“打开施工进度”，会进入当前项目的只读施工进度页。页面仍核对同一项目和来源；未接入时显示原因，不自动切换到别的项目。

点击“返回首页项目”，会回到原项目。项目已经更名时显示最新名称；如果项目被删除或权限改变，会显示明确提示，不替换成列表里的第一个项目。

存在可读排程时，可以展开楼栋分组，横向滚动甘特时间轴，并点击工程量联动工序查看对应完成事实。工程量页提供返回原首页或施工进度工序的入口。手动填报工序只显示只读提示。

## 五、小屏与键盘操作

在手机等小屏上，项目选择器使用全屏选择面板。搜索后按 Enter 选择；按 Escape 关闭并回到触发按钮。甘特只在自己的区域横向滚动，页面正文无需左右移动。

## 六、已定稿待开发与适用范围

正式中央项目的排程读取与写入闭环继续由施工进度模块承接。当前不提供从首页为正式项目新增楼栋分组、编辑计划或填写实际进度的入口。

既有桌面本地排程维护流程继续保留。本指南的浏览器中央读取验收不代表生产服务或持久化部署已经完成。
