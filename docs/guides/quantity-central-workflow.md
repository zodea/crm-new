## 使用范围

本指南对应浏览器工程量管理。配置正式存储的工作区从同一磁盘读取和保存区域、模板、阶段、责任、完成、照片及空鼓原件；读取不会初始化 Native 全库或复制班组、工人主档。演示来源只读，权限或来源失败时不能回落开发资料。整机部署仍是独立后续范围。

区域、模板、清单关联、阶段、责任、完成照片、归档和导出已经完成本地真实操作验证，日常三类文件映射导入也已通过实际文件验收。可见操作及验证边界以[本次验收记录](../design/evidence/issue-442/ui-verification.md)及[实现状态](../design/ui-implementation-status.md)为准。

## 完整操作顺序

:::flow
步骤一|选择项目|确认项目名称和正式或演示来源。
步骤二|建立户型模板|维护房间、分项和三量；正式新清单关联须等上游采用边界开放。
步骤三|建立施工区域|依次建立楼栋、楼层和户，每户挂接本项目模板。
步骤四|配置阶段与报量|选择阶段关联分项，再为分项显式选择报量阶段。
步骤五|配置当前责任|按户与工种选择班组或个人；必要时明确个人范围。
步骤六|登记施工完成|选择户与阶段，填写日期和照片；缺照片可先存草稿。
步骤七|核对与导出|刷新施工记录，核对历史责任、阶段进度和工程量台账。
:::

## 项目与来源

进入“分包及人工 → 工程量管理”，从项目选择器选择项目。正式和演示即使名称或编号相同，也属于不同来源；演示项目会显示只读说明。

项目目录读取失败、分页不完整或权限变化时，先使用重新读取。系统不会用演示记录替代失败的正式记录。进入模板、区域、阶段及户详情后，返回入口保留当前来源。

## 户型模板、三量与合同清单

1. 在工程量管理点击“户型模板”，新建空白模板，填写户型编码和名称。
2. 默认保留整户范围。可增加房间和手工分项；分项编码、工种、单位应明确。
3. 每条明细选择房间和分项，再切换“录入来源”填写合同量、暂估量或现场算式。切换录入口径不会清空另外两量。
4. 正式工作区的新增施工合同清单关联当前保持关闭；历史迁入的稳定清单引用及原识别量保留，只作原链证据。开发适配中的清单选择不代表正式上游已经采用。系统不按同名分项猜关联。
5. 保存后重新读取。挂接该模板的户使用更新后的模板；借用模板新建的是独立快照，之后不会跟随来源模板变化。

| 输入或动作 | 保存与回读 |
| --- | --- |
| 明确输入 0 | 保留为已知零 |
| 留空 | 保留未填写，不用其他量补值 |
| 输入现场算式 | 校验并计算现场量，原算式一同保留 |
| 新选清单 | 显示并保存所选清单的原识别量 |
| 普通修改同一关联 | 保留原识别量，不以当前审批增量覆盖 |
| 解除清单关联 | 去除关联，旧识别值标为“原识别值”供历史核对 |

保存失败或编辑版本冲突时，输入留在当前页；不要反复新建同名模板替代重试。离开后返回未保存模板，系统会重新核验权限；失败可使用“重新核验权限”，原草稿和编辑版本仍保留。

正式提交结果未知时，页面显示原提交编号并阻止新的保存。先点击“核对原提交”；原结果已应用但保存后读取失败时，只重读同一工作面。刷新会恢复原编号、身份和范围，不在浏览器存储字段草稿、照片正文或完整原库。明确未应用的原编号会封存，迟到请求不能重建。另一项目、另一户、演示来源或身份变化不能核对原目标。

保存按本次实际消费的目标、模板、阶段、人员资格及责任/完成关系核对版本。同项目无关楼栋、别模板或未选择人员变化不会一概阻止保存；原选定关系发生变化时保留输入重新读取。编码重复等唯一性仍在保存事务中核对。

已保存模板的编码和明细身份保持稳定。删除受现有挂接关系约束；页面提供的撤销入口只针对对应保存操作。归档后的修改或撤销需要再次确认，取消不会变更模板。

## 楼栋、楼层与户

从工程量管理点击“项目区域”。先填写楼栋编码和显示名称并新增，再选择楼栋新增楼层，最后选择楼层新增户。新增户时必须选择本项目户型模板。

楼栋、楼层和户逐次保存。保存成功后输入框清空，列表显示服务回读的结果；保存失败则保留当前输入。项目没有模板时，可由区域页进入模板整页建立后再返回。

窄屏中三个区域依次排列；当前楼栋和楼层的选择仍可见。点击“打开工程量矩阵”返回同一项目来源，确认户已出现在矩阵中。

## 阶段与唯一报量选择

“阶段配置”是独立整页。新阶段填写编码、名称、工种和完成方式，并明确关联分项。新建阶段不会自动成为报量阶段。

每个分项在“报量阶段”处选择一个阶段，或者明确不设置；逐行保存。修改两行而只保存一行时，另一行未保存选择继续保留。

阶段编码、工种和完成方式是已保存阶段的稳定身份；名称和顺序可按当前规则维护。手动完成阶段不建立工程量分项映射。已有映射无法读取时应先解决读取问题，不能借保存其他字段隐式移除映射。

## 当前责任与完成时责任

在矩阵点击“责任配置”，选择工种和班组或个人，再勾选具体户或当前楼栋全部户。候选来自当前可用基础资料及其工种、活项能力。

班组责任按整户工种维护。个人可负责整户工种，也可明确房间与分项；只有部分活项能力的个人须选择兼容范围。

替换已有责任时会显示涉及的户和原、新责任，确认后才保存。当前责任可以变化，已完成记录中的“完成时执行责任”仍保留当时事实，不会随当前责任一起替换。

## 单阶段完成与验收照片

从矩阵进入户施工详情，在需要登记的阶段点击“登记”。核对当前责任、三量及已有施工记录，填写完成日期和备注，并添加验收照片。

:::flow
步骤一|选择户与阶段|读取当前责任、原完成记录及当前权限。
步骤二|填写完成输入|日期、备注和新增照片留在当前登记窗口。
步骤三|检查缺照片提示|取消会保留输入；选择保存到草稿不会冒充已完成。
步骤四|补齐照片再登记|照片随完成事实保存，完成时责任留为历史事实。
步骤五|刷新并核对|户详情读取同一照片正文、状态和完成时责任。
:::

没有当前有效责任时不能直接登记完成，应先配置责任。上一阶段尚未完成或缺验收照片会显示风险提示，按当前规则继续处理；提示本身不会替代本次登记事实。

在户详情点击照片名称可查看已保存正文。照片读取失败时显示原因，不以本地同名图片替代。关闭预览会取消本次读取，迟到结果不会覆盖后续打开的照片。

## 批量完成、归档与导出

“批量完成”先选择工种和户，再点击“展开阶段”。逐项核对，排除不应提交的阶段后确认。已有完成项默认排除；缺照片或缺责任的待处理项按软卡规则存草稿。提交结果按阶段显示，不把整个工种写成一条完成记录。

“归档矩阵”及“解除归档”均有确认。归档后的模板、责任和完成修改需要再次确认；取消保留输入，不会解除归档或写入业务事实。

确认归档时若已切换项目或来源，原确认失效；请在当前项目重新操作。台账导出先选择保存位置，再读取当前事实并生成文件，网络慢时无需反复点击。分类导出先进入独立配置页，核对“楼栋 → 工种”目录与“楼层-户”文件名后开始；准备期间切换项目不会迟到打开旧项目配置，已打开的导出配置可作为独立工作页继续。

户详情按单位核对阶段小计和全户合计，宽表仅在表内横向滚动。台账和分类导出使用重新核验后的当前来源事实；权限撤回或读取失败时停止导出。具体字段和缺量示例见[工程量合计与台账导出](quantity-totals-and-export.md)。

月报入口及三量选择见[施工合同与清单指南](core-contract-and-boq.md)。工程量模板后来改量，不应改写已经提交的月报或已发放工资快照。

## 导入与迁移的区别

旧库受控迁移用于带入已有区域、模板、阶段、责任、完成与照片，须经过预检、确认和对账，详见[本地数据迁移指南](local-data-migration.md)。

日常导入分为“户型模板量”“责任配置”“阶段完成”三类。先在工程量管理点击“导入”，选择目标，再进入文件映射页核对列对应关系、预览逐行结果并提交。浏览器正式来源统一通过中央命令处理；三类操作已用实际 CSV 验证，与旧库迁移分别记录证据。

| 导入目标或字段 | 文件中如何填写与核对 |
| --- | --- |
| 项目编码 | 使用当前项目的唯一编码，不能用项目名称代替或自动猜测 |
| 楼栋、楼层与户 | 使用本项目已存在区域的完整编码组合，导入量或责任不隐式新建区域 |
| 户型模板量 | 分别映射合同量、暂估量和现场量；留空与明确的 0 含义不同 |
| 责任配置 | 班组、个人二选一；名称须在当前候选中唯一，替换现有责任时“允许替换”填“是” |
| 阶段完成 | 使用当前项目阶段和有效责任；缺少验收照片的 completed 行会被拒绝，可明确填 draft 后到户详情补照 |
| 完成日期 | CSV 保留 YYYY-MM-DD 原文；Excel 日期单元格也应显示为 YYYY-MM-DD，例如 2026-09-11 |

预览有错误时先修正对应行。失败重试沿用原行的命令身份，避免重复保存；已保存但回读失败时停止当前行并重试核对，不把未知结果记成成功。系统不会把缺照片的 completed 行自动改成草稿，也不会按同名对象猜关联。

## 异常时如何继续

户内新增“空鼓检查与整改”入口的操作、原责任保留及整改销记见[户级空鼓指南](./payroll-hollow.md)。该链路的 P6 验收状态独立标明；记录空鼓和整改不自动扣工资。

| 所在位置 | 可见结果与下一步 |
| --- | --- |
| 项目或来源读取失败 | 重新读取；不改用另一个来源冒充原记录 |
| 表单保存失败或版本冲突 | 保留输入，核对当前事实后按明确结果继续 |
| 返回缓存表单时权限读取失败 | 使用原地重新核验，保留尚未保存草稿 |
| 完成登记缺照片 | 取消留在输入，或保存到草稿后补照片 |
| 替换责任或修改归档数据取消 | 原事实不变，当前输入保留 |
| 照片、台账或分类导出失败 | 在同一来源重试，不借用旧缓存内容 |

完整数据和业务定义只看[工程量页面蓝本](../rewrite/pages/subcontract-quantity.md)、[读取模型](../rewrite/READ-MODELS.md)与[命令契约](../rewrite/COMMANDS.md)。本指南不扩展工资算法或审批规则。
