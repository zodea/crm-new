## 三、新建并打开项目

### 3.1 新建项目

1. 打开左侧菜单“项目信息”。
2. 进入“项目列表”。
3. 点击右上角“新增项目”。
4. 填写项目名称、项目编码、客户、项目经理和计划工期。
5. 点击保存。

```text
项目信息 -> 项目列表 -> 新增项目
```

### 3.2 保存后从哪里打开

- 回到“项目列表”，点击项目名称进入项目详情。
- 在项目详情的“施工进度排程”卡片点击“打开完整排程”。
- 也可以从左侧“项目信息 -> 施工进度”进入，再选择对应项目。

### 3.3 新建施工合同

1. 打开左侧“主合同管理”。
2. 进入“施工合同”。
3. 点击新增并选择刚建立的项目。
4. 保存合同基础资料。
5. 在合同下挂工程量清单附件。
6. 完成清单拆表和人工确认。

只有清单行中明确填写的楼栋才能作为排程楼栋范围。

## 四、当前工程量操作

当前系统支持在已有楼栋、楼层和户的项目中维护手工工程量。

1. 进入“分包及人工 -> 工程量管理”。
2. 选择项目。
3. 点击“户型模板”。
4. 新建或选择户型模板。
5. 配置房间。
6. 点击“新增手工分项”。
7. 填写分项编码、名称、工种和单位。
8. 填写合同量、暂估量或现场复核算式。
9. 保存户型模板。

| 数量 | 当前用途 |
| --- | --- |
| 合同量 | 对照合同清单和计价；允许人工复核 |
| 暂估量 | 施工前期计划、工资和成本预估 |
| 现场量 | 保存现场复核算式和计算结果 |

> 工程量描述“做多少”，阶段完成描述“何时完成”。两者不能混为一套数据。

## 五、建立楼栋分组

当前已经实现的是施工合同清单模式。

1. 进入“项目信息 -> 施工进度”。
2. 选择项目。
3. 点击“新建楼栋分组”。
4. 选择施工合同。
5. 填写分组名称和计划开始日期。
6. 从合同清单范围中选择楼栋。
7. 选择工序搭接方式。
8. 启用或停用标准工序。
9. 调整工期和锚点开始日期。
10. 点击“生成排程”并确认。

无法生成时优先检查：

- 是否选择了项目和施工合同。
- 合同是否完成清单拆表。
- 清单是否包含明确楼栋。
- 是否至少选择一栋楼和一道工序。

## 六、标准工序与调整

当前 22 道标准工序来自现场进度计划表中的精装修工序样本。

生成前可以：

- 启用或停用工序。
- 修改工期。
- 设置锚点开始日期。

生成后点击工序详情可以：

- 修改计划开始和完成日期。
- 设置前置工序和 FS 间隔天数。
- 调整个别楼层计划日期。
- 删除工序。
- 手工填写无工程量来源工序的实际进度。

全局工序模板维护入口尚未实现，后续完成后再补指南。

## 七、日常维护实际进度

### 7.1 有工程量来源的工序

1. 在施工进度中点击工序。
2. 点击“查看工程量”。
3. 系统进入工程量矩阵并定位到对应楼栋分组和工序阶段。
4. 按户登记阶段完成日期和验收资料。
5. 排程按已完成户数和应做户数自动汇总实际进度。

有工程量来源的工序不能在排程页另填一份完成率。

### 7.2 没有工程量来源的工序

放线、给排水、电线、门、柜、洁具和保洁等工序，可以在工序详情中手工填写 0% 至 100% 的实际进度。

### 7.3 调整计划

- 修改日期后检查 FS 依赖冲突。
- 个别楼层可以单独微调日期。
- 正式执行前可以设置基线。
- 调整后的当前计划与基线分别保留，用于比较偏差。

## 八、常见问题

| 问题 | 当前处理 |
| --- | --- |
| 页签显示“未命名” | 路由标题显示问题，不代表排程数据没有名称 |
| 合同存在但楼栋范围为空 | 检查清单是否拆表，以及清单行是否有明确楼栋 |
| 已选 0 栋仍显示预计日期 | 日期来自工序模板计算；没有楼栋仍不能生成 |
| 工序实际进度不能手工修改 | 有工程量来源的工序必须从阶段完成自动汇总 |
