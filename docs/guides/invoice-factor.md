## 一、当前已可用

从资金管理进入“开票因子”，顶部计算税额，下方维护因子并查看组合。一个含税金额同时作为组合求解目标。本工具只计算和复制结果，不生成发票、申请或付款记录。

| 能力 | 当前范围 |
| --- | --- |
| 即时税额计算 | 价税合计、不含税金额、税额和含税金额大写 |
| 精确组合 | 只给出金额恰好相等的组合，支持数量上限和小数数量 |
| 包含或排除因子 | 已计算后修改条件会自动重算 |
| 复制 | 点击税额格、整条表达式或单个使用项；也支持键盘 |
| 配置恢复 | 同一浏览器保留金额、返回数量和因子，包括明确清空的内容 |

## 二、先填一个金额

1. 在顶部“含税金额”填入目标金额，税率填写 1～13 的整数。
2. 四格立即显示结果，点击任一格即可复制对应的完整金额或大写。
3. 税额与不含税金额按分计算，两者相加等于价税合计。

首次使用的示例金额为 128640，税率 13%。不含税金额为 113840.71，税额为 14799.29。已有保存配置不会被该示例覆盖。

## 三、求解开票因子

:::flow
当前已可用|维护因子|填写单价；最大数量留空表示不限
当前已可用|按需限制|设置必须包含或排除因子，调整返回数量
当前已可用|开始计算|直接使用顶部含税金额作为目标
当前已可用|核对结果|查看本轮目标、总解数、耗时与完整表达式
当前已可用|复制使用|复制整条表达式或单个使用项，再到实际业务中人工核对
:::

首次因子为 640 和 960，两者不限数量、不勾“小数”。点击“开始计算”后，128640 可得到 68 条精确解；页面进入时不会自行求解。

- 不勾“小数”时，因子的使用数量只能是整数。勾选后，也只生成单价乘数量恰为整分的组合。
- 默认显示最多 100 条，最多可设为 5000 条。达到上限或超时时，以结果摘要注明的数量和范围为准。
- 已有结果后，包含或排除条件变化会自动重算。修改金额、因子或返回数量后，点击“开始计算”。
- 输入已变而尚未重算时，结果区的“本轮目标”仍显示原来那一轮的金额，避免把旧结果误用于新金额。

## 四、失败、取消与保存

金额为空或无效、没有有效因子时，不能产生有效组合；空金额也不会显示可以复制的零税额。税率越界会收敛到 1 或 13，小数税率不会进入计算。

计算较久时可取消；新一轮完成前保留上一轮结果。超过时限或无法完整计数时会明确显示限制，不把部分结果称为全部结果。

配置在当前浏览器保存。刷新保留自定义值、旧版配置、空金额和已删除全部因子的状态；结果需重新计算。它不是中央业务保存，也不跨设备同步。

小屏按税额、因子、结果依次排列；结果表可在自身区域横向查看完整表达式。使用 Tab 聚焦复制格或按钮，Enter 执行操作；问号说明可用 Escape 关闭并回到原按钮。
