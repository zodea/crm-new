## 二、导入发票 Excel

1. 进入“资金管理 → 发票台账”，点击“导入 Excel”。
2. 如果没有现成文件，先点击“下载发票模板”。模板包含“发票导入”工作表和“填写说明”工作表，填写后保存为 `.xlsx` 再上传。
3. 拖入 `.xlsx`、`.xls` 或 `.csv` 文件，或点击上传区域选择文件。
4. 如果工作簿包含多个 Sheet，选择实际业务明细 Sheet；系统会显示表头行、数据行数、合并区域和公式数量。
5. 点击“使用此工作表”，在字段映射步骤确认发票号码、价税合计、供应商、发票日期和归属项目等字段。
6. 在预览步骤删除标题行、合计行或不属于发票明细的行，确认后开始导入。

系统会自动展开数据区域的合并续行，使同一供应商、项目或票据分组的每一条业务行都获得对应值；标题合并只作为来源布局信息显示。表头行可以位于标题行之后，不要求固定在第一行。

缺少发票号码但仍含供应商、金额等业务内容的行会保留来源工作簿、Sheet 和行号，进入逐行复核；系统只忽略带“合计”“总计”等明确标记的非业务行，不会仅因票号为空而静默丢弃。

### 归属和异常

- 发票号码和价税合计为必填字段，金额必须大于 0。
- 归属项目必须唯一匹配现有项目；个人费用请在归属项目列填写“个人开支”。缺归属、项目不存在或项目不唯一的行会逐行拒绝；导入会继续处理其他行，并在完成后保留拒绝清单，可下载为 CSV 交给业务人员修正后重导。
- 发票号码已存在时，系统只补充原记录中的空字段，不覆盖已确认的业务值。
- 公式单元格使用 WPS/Office 已保存的显示缓存参与预览；如果缓存为空或异常，请删除该行并留待人工复核。系统不会把公式文本直接当作金额。

## 三、导出台账 Excel

1. 在发票台账中先选择左侧归属节点，并按搜索框或列筛选缩小范围。
2. 点击“导出 Excel”，先打开“导出 Excel 预览”。预览中的表格就是实际将写入文件的业务数据，不是效果图。
3. 核对行数、发票号码、供应商、归属和金额后，点击“确认导出”；取消则不会保存文件。
4. 导出文件包含标题带、发票日期、发票号码、供应商、票据类型、价税合计、归属项目、来源和备注，以及最后的合计行。

导出文件保留金额数值、日期/金额格式、列宽、标题合并和连续相同供应商/归属项目的纵向合并。格式参照、公式兼容结论和后续 XLSX 样式配置见 [`real-ticket-excel-reference.md`](../rewrite/pages/real-ticket-excel-reference.md)。

## 四、使用边界

- 导入完成后，未指定归属的记录不会直接进入已归档台账；需要回到待归档记录补充归属并执行归档。
- 导入只处理当前选中的工作表，不会把“汇总”或其他导航 Sheet 自动当成发票明细。
- 解析器不负责替代 Office/WPS 重算。当前环境未进行 Office/WPS 双引擎视觉回归，正式交付前应在目标环境检查公式重算、合并显示、打印分页和日期/金额显示。
- 打印排版在当前工作台内完成；切换到打印模式后窄屏会自动展示排版面板。点击打印后，系统打印窗口关闭，再在页面底部确认“已完成打印”或“未打印”，不会再弹出第二个确认窗口。
