## 使用范围

本指南说明工程量管理中的户施工详情，以及“工程量台账”的月度完成量导出。页面读取当前户型模板的合同量、暂估量和现场量；完成记录仍保留完成当时的执行责任。

这里的“当前已可用”限定本次验证的本地浏览器流程。工程量中央迁移、正式服务读写和生产持久化仍待开发与验收，不能据此作为上线结论。完整状态见[实现状态](../design/ui-implementation-status.md)。

## 查看阶段小计与全户合计

1. 打开工程量管理并选择项目、楼栋和视图。
2. 进入需要核对的户施工详情，按工种和阶段查看量明细。
3. 每个阶段的分项小计按计量单位分别显示；全户合计也按单位分开。例如，平方米和米会显示为两组，不相加为一个数。
4. 同一房间的同一分项被多个阶段引用时，全户合计只计一次。阶段小计仍各自反映该阶段对应的明细。

窄屏中可以在量明细表内左右滚动，页面本身不需要横向滚动。通过“返回工程量矩阵”回到来源页面继续查看。

## 识别缺量与明确零

合同量、暂估量和现场量分别检查，不会互相补值。

未标明计量单位的分项合计显示“单位待核对”，不提供合计或已知部分。先核对分项单位，再计算总量。

| 情况 | 合计显示 | 如何核对 |
| --- | --- | --- |
| 全部参与明细有值 | 显示完整合计 | 按当前单位核对明细 |
| 全部明确填写为 0 | 显示 0 | 这是已知零，不是缺失 |
| 有一项或多项未填写 | 显示“—”和缺项数 | 查看合计旁的说明，核对已知部分和参与项数 |
| 所有参与明细都未填写 | 显示“—”和缺项数 | 没有可用的已知部分 |

例如，同一单位两项现场量分别为 12 和未填写，完整现场量合计显示“—，缺 1 项”；说明中的已知部分为 12。补齐缺项前，12 不代表完整工程量。

合计说明支持鼠标、键盘和触摸。缺量应回到对应户型模板核对；模板保存后，挂靠该模板的户按活链接重新读取。此操作不改写已生成报量单或已发放工资的冻结事实。

## 导出工程量台账

1. 在工程量管理中选定项目。
2. 使用台账导出入口，选择保存位置并保存 Excel 文件。
3. 打开文件中的“施工记录”“阶段进度”和“月度完成量”三个工作表。

“月度完成量”按月份、工序阶段和计量单位分行，只计实际已完成且明确承担报量的阶段。多阶段共用分项不会重复带量。

每行包含三量、各自的完整度和已知部分。完整零保存为数字 0；完整量未知时数值格留空，并通过完整度列说明缺项。已知部分只在合计不完整时提供，不能与完整合计混用。

同一完成户可能涉及多个单位，因此在不同单位行中分别计入该行的完成户数。不要跨单位把这些户数再相加，作为项目完成户总数；项目阶段进度应看“阶段进度”工作表。

## 失败与复核

没有可导出数据时，页面提示当前项目没有工程量数据。导出失败时，页面保留原筛选和施工事实，可修正原因后重试。

Excel 中的缺量信息与户详情采用同一完整度含义。遇到空值、异常单位或数据不符，应核对源模板、完成日期和报量阶段，不能手动将缺失值改成 0 来消除提示。
