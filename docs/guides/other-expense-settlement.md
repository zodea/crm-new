## 一、从合同开始

1. 打开“项目其他合同 → 其他支出合同”，搜索并点击真实合同名称。
2. 在只读详情切换到“支出结算”，点击“新建结算”。草稿合同不能作为结算来源，需先补全并提交合同。
3. 新建表单自动带入项目、合同和分供方。更换项目后必须重新选择该项目下的非草稿其他支出合同，不能输入名称代替真实关系。
4. 填写结算名称、日期、含税金额、类型、期间及备注；如需无税金额，填写税率。真实零金额可以保存，未填写金额不会自动当作零。
5. 登记附件后显式点击“保存”或“保存并提交”。默认保存后进入只读详情；取消“保存后关闭”可留在编辑页。“保存并新建”保存本单后打开下一张空白表单。刷新仍读取同一条中央结算。

“查看全部结算”打开限定该合同、项目和分供方的结算列表。也可直接从菜单进入结算列表，使用搜索、项目和状态筛选。

## 二、查看与核对

名称主链接始终进入只读详情。详情保留基础资料、合同金额、前期结算、本次结算、累计与应付金额、附件和系统审计信息。

| 金额 | 核对口径 |
| --- | --- |
| 含税结算金额 | 当前结算显式保存的金额 |
| 奖罚扣款合计 | 该结算实际有效抵扣事实 |
| 本次结算金额 | 含税结算金额减有效抵扣 |
| 累计已申请付款 | 有效付款申请中分配到本结算的金额 |
| 剩余可付款金额 | 本次结算金额减累计有效申请 |
| 累计已付款金额 | 已确认支付且能精确归属本结算的分摊 |
| 剩余未付款金额 | 本次结算金额减累计已付 |

无有效记录的真实空集合显示零；没有记录金额、关联已失效或支付涉及多个结算而缺少结算级分摊时显示“未记录”。不要据此把未知金额当作零。

点击项目、合同、分供方可进入其只读详情。“奖罚抵扣”“付款申请”“支付事实”页签显示真实关联；“查看关联事实”按稳定身份重新读取中央源单，展示罚扣整改资料、付款申请批复资料或支付凭证、分配记录和附件元数据。申请中可查看关联支付，支付中可查看来源申请；刷新后仍保留所选源单，“返回来源单据”逐级回到上一张源单，再返回关联列表。源单读取失败可以单独重试；真实源单已删除、身份失效或关系错配时明确说明，不按名称、编号或金额连接其他单据。

## 三、编辑、提交与确认

在详情点击“编辑结算”进入独立整页表单。保存草稿允许资料暂不完整，普通保存校验必填资料。“保存并提交”进入待确认；待确认结算可在编辑页明确“确认结算”，确认后只读锁定。此确认是结算业务状态，不代表外部审批系统已审批通过。

已有关联事实或事实尚不完整的结算不能改挂其他合同。保存失败会保留输入和附件改动，直接重试不会重复创建。出现版本冲突时，可保留自己的输入，或选择载入最新版后继续；系统不会覆盖其他会话的新版本。

附件当前只保存名称、大小、分类、上传人和时间等元数据。选择文件并不表示原件已上传归档，文件正文预览和下载仍未交付。缺失的历史创建人、负责人和审批记录显示未记录。

## 四、逐级返回与异常

优先使用“返回来源”：依次返回事实列表、结算列表、合同详情及起始合同列表。搜索、页码、状态、项目来源、页签、锚点、滚动和行焦点随来源保留。没有合法来源时返回结算列表。未保存表单离开前需确认放弃；Escape 可取消并返回操作焦点。

| 页面状态 | 处理方式 |
| --- | --- |
| 暂无结算 | 从真实非草稿合同创建 |
| 无筛选结果 | 清除或调整筛选 |
| 读取失败 | 点击重新加载 |
| 保存失败 | 保留输入并重试 |
| 无权限 | 联系权限管理人员核实 |
| 未找到、来源或合同错配 | 返回来源重新进入，不修改 URL 猜测关系 |
| 关联事实不可用 | 核实原始稳定关系，不把未知当作无记录 |

## 五、当前边界

当前已可用：浏览器开发验证环境中的结算中央读写、专属详情、整页编辑、附件元数据、关系事实核对及来源往返。旧数据经“设置 → 数据迁移”的备份、试跑、导入及确认后接管。

已定稿待后续开发：生产持久化服务、完整文件正文及外部审批集成。中央端仍是可重置测试实例，服务重启可能清除测试记录，不应作为生产业务存储。材料采购结算的到货分摊与冲销不属于本功能。
