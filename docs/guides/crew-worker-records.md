> 适用范围：浏览器中的“基础信息 → 班组管理 / 工人信息”。中央列表、详情、新增、显式编辑、班组成员增删，以及班组—工人—项目—工程量责任—工资—扣罚关系已经可用。中央附件存储尚未接入；桌面版仍使用本地数据路径。

## 1. 这条链路能做什么

班组和工人是跨项目共享的基础档案。现在可以：

- 搜索正式档案，并按工作区开关决定是否同时查看测试数据；
- 从班组查看成员、关联项目、责任与工资汇总、扣罚事实；
- 在正式班组详情直接加入、转入或移出成员；
- 从工人查看所属班组、当前项目、直接责任单元、工资单和扣罚单；
- 使用蓝色名称进入已有详情，并返回原列表或原班组/工人详情；
- 从正式详情显式进入编辑，保存后读取中央最新版本。

页面不会按姓名猜测关系，也不会用整张工资单或参考日工资反推个人已分配金额。

## 2. 查找班组或工人

1. 在侧栏进入“基础信息”。
2. 选择“班组管理”或“工人信息”。
3. 使用搜索框输入班组名称、负责人、工人姓名、手机号或证件号片段。
4. 可按工种和排序方式缩小范围。
5. 如需查看测试数据，打开顶部“测试数据”开关；测试档案会明确标注“测试”，且只读。

列表中的电话、身份证号已经脱敏。正式数据与测试数据来源隔离，同名记录仍是不同档案。

## 3. 新增正式班组

1. 在班组列表选择“新增班组”。
2. 填写班组名称、主工种、负责人和联系电话。
3. 按需维护能力工种、能力活项、默认发放比例、补贴和管理提成。
4. 选择“保存”或“保存并提交”。
5. 保存成功后进入该班组中央详情。

班组名称不能与现有正式班组重复。浏览器不会把班组保存到本地数据库。

## 4. 新增正式工人

1. 在工人列表选择“新增工人”。
2. 填写姓名、联系电话、主工种、开户银行和银行卡号。
3. 在“所属班组”中选择中央正式班组；不要手工录入班组名称代替选择。
4. 按需选择中央正式项目，设置在场状态、进退场日期和安全教育状态。
5. 保存后进入该工人中央详情。

如果所属班组不存在、来源不一致或无权使用，保存会被拒绝，不会自动创建或猜测班组。

## 5. 查看班组关系

班组详情包括班组主档和班组级计薪默认值、成员及当前项目、按“在场成员 / 工程量责任 / 工资单”去重聚合的项目，以及班组扣罚。

工人名称可进入工人详情，项目名称可进入项目详情，扣罚单号可进入项目扣罚。没有成员、项目或扣罚时，页面显示相应真实空态。

### 5.1 添加或转入成员

1. 打开正式班组详情，在“成员”区选择“添加成员”。
2. 从现有正式工人中选择目标工人；候选项会标明当前班组或“未分组”。
3. 选择未分组工人后，直接确认“加入班组”。
4. 若工人已经属于其他班组，页面会再次显示原班组和目标班组；确认后才会转组。
5. 保存成功后，成员表和班组人数会读取中央最新结果。

添加成员不会新建重复工人，也不会按姓名猜测身份；关系始终写到所选工人的稳定 ID。

### 5.2 移出成员

1. 在成员所在行选择“移出班组”。
2. 阅读确认提示后，再次选择“移出班组”。
3. 页面刷新后，该工人不再属于当前班组，但工人档案仍可正常打开。

移出只清空工人的当前班组归属，不删除工人、工资单、工资分配、扣罚或其他历史事实。班组和工人仍直接进入工资流程，不需要另建合同关系或专项票。

## 6. 查看工人关系

工人详情包括脱敏个人信息、能力、安全教育、所属班组和关联人员，并列出项目、直接责任单元、工资单中的工人行金额与个人分配，以及工人本人或责任人命中的项目扣罚。

责任单元进入工程量户只读事实，工资单进入工资只读事实，扣罚单进入项目扣罚只读事实。这些页面的左上角返回按钮会回到原工人或班组详情。若历史数据没有个人工资分配，页面显示“历史未记录”，这不是 0 元。

## 7. 编辑、冲突与返回

- 只有正式详情且当前账号具备相应写权限时才显示“编辑”和成员操作；编辑使用独立整页表单，列表不提供快捷编辑或本地删除。
- 若服务器版本已变化，页面会让你选择保留当前内容后重试，或改用服务器最新版。
- 从带搜索、工种、排序或页码的列表进入详情后，返回列表会恢复原来源；班组与工人互相穿透时也可返回原详情。

## 8. 隐私、附件与异常状态

- 电话只保留前 3 位和后 4 位；身份证号和银行卡号只保留前 4 位和后 4 位。编辑表单可读取授权范围内的原值，但只读详情不展示完整敏感信息。
- 当前浏览器中央附件边界尚未接入。页面会明确提示，不会把本地附件伪装成中央正式附件。
- “无权查看”“服务暂不可用”“记录不存在”“来源不匹配”和“真实空态”是不同状态，请按页面提示处理。

## 9. 当前仍未提供

- 班组合同关系；
- 班组 × 项目的单价配置；
- 浏览器中央附件上传；
- 根据名称、备注或金额自动匹配关系。

这些能力在建立明确数据关系和权限边界前，不应通过备注或本地副本绕过。
