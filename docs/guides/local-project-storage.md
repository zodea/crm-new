# 本机项目保存、原件与 Excel 导入

对应 [#452](https://github.com/zodea/crm-new/issues/452)。当前在独立合成工作区验证项目磁盘保存；正式资料写入仍受独立介质备份和最终上线门禁保护。登录与本机维护配置沿[客户保存指南](./local-customer-storage.md)，不需要为项目另配数据库或维护人。

## 保存项目

从项目列表新建或从详情进入编辑，沿现有项目字段填写并选择真实客户。名称、客户和项目经理按既有规则校验；客户及次客户须存在、可读且未停用或删除。客户改名后项目仍沿原 ID 显示新名称，不按文字改挂其他客户。

附件区显示“原件随项目一同保存”时，单份可选不超过 10 MiB 的原件。正文、描述、版本、审计和成功回执同时保存。保存后从编辑页“下载原件”读取原文件；浏览器草稿不存原件正文。项目没有套用客户的九份附件数量限制。

版本冲突会保留当前输入，选择使用最新内容或以最新版本继续更正，不能静默覆盖。项目名称、日期、金额和已登记编号按既有表单保留；本功能不新增审批政策。

## 提示丢失和重启

失败提示不一定表示没有保存。再次保存时先核对原提交；已提交就采用原项目和附件后再作更正，未提交就封存原编号，防止迟到请求重写。

刷新或服务重启后，重新登录并到项目列表，在“上次项目提交需要核对”打开原入口。浏览器仅保留工作区、维护人和页面目标对应的提交编号；读回失败会继续保留编号。关闭整个浏览器会话后不承诺找回未核对编号，应先查列表中的真实结果。未保存字段和原件没有离线正式保存能力。

## 删除和恢复

项目详情“项目保存与恢复”可确认删除；取消后焦点回到原按钮且事实不变。删除项目不物理删除原件、客户或历史导入回执；正常列表移除，删除期间禁止编辑和原件下载。列表“已删除项目”可进入并恢复，附件各自原有的删除状态不被重置。

## Excel 导入

操作仍见[项目 Excel 导入指南](./project-excel-import.md)。文件摘要、Sheet、原始行和非空外部旧 ID 的防重回执现在与项目同库保存，重启、并发或重新上传不重复新建同一来源。相同来源出现不同内容会冲突，需进入原项目显式编辑。外部旧 ID 原文如 `0007` 保持字符串；它不是新项目的系统 ID，也不自动接管整库迁移的旧 ID 映射。

导入采用准备时的稳定客户身份；客户失效、停用或权限变化会拒绝该行。部分成功和失败行重试继续沿既有导入页面，不能把未确认的提交跳过为成功。

## 当前边界

项目基础事实、客户双向关系、原件、版本、审计和导入回执已纳入同库参与者。材料合同、项目分供方、收款、预算、工资和其他未接管的正式领域保持未知或不可用；项目保存通过不能解释成经营数据已经齐全。进程重启验证不等于物理断电实验。
