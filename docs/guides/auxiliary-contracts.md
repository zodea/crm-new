## 一、选择正确的合同类型

| 类型 | 适用情况 | 必需的业务关系 |
| --- | --- | --- |
| 其他支出合同 | 项目机械租赁、检测服务及其他支出 | 真实项目与乙方分供方 |
| 公司支出合同 | 房租、软件及公司层面的其他支出 | 对方单位名称；不挂项目 |

公司支出合同没有项目筛选和项目字段，无需建立“公司”虚拟项目。项目其他收入合同不属于本功能。

## 二、查找与查看

1. 从“项目其他合同”进入其他支出合同或公司支出合同。
2. 按类别、状态或名称、编号、对方单位搜索。其他支出合同还可以按项目筛选。
3. 点击合同名称打开只读详情。进入页面不会保存或提交合同。
4. 在“详细资料”查看基本信息、合同条款、备注、附件记录和创建、修改信息。不存在的历史字段显示“未记录”。
5. 使用“收票登记”“付款信息”页签核对所属合同的记录；其他支出合同另有“支出结算”“增补合同”。没有记录时显示对应空态。

列表底部的数量和金额合计按当前筛选范围统计，不仅统计当前页。真实零金额显示为零；未记录金额不按零计算。

## 三、编辑与保存

1. 在详情点击“编辑合同”，进入独立整页表单。
2. 核对合同类型、项目或对方单位，再填写金额、日期、付款周期、条款和备注。
3. 其他支出合同的项目和分供方必须从候选中选择。名称相同不代表同一个对象，不可用自由文本代替关联。
4. 点击“保存”写入当前合同；默认保存后返回详情，刷新后仍从同一中央记录读取。已有合同的业务状态不会因普通保存被改回草稿。
5. 新建合同可以“保存草稿”暂存不完整资料；“保存并提交”会校验必填项并进入审批中。本功能不提供审批通过、结清等结果动作。

保存失败后输入和待处理附件会保留。服务恢复后直接重试即可；同一次内容的重试不会重复创建合同。如果提示合同已被更新，可保留自己的输入，也可明确选择载入最新版，避免覆盖其他人的修改。

离开有未保存内容的表单时会显示确认框。取消或按 Escape 保留输入，并将焦点返回原操作按钮。

## 四、附件与票款口径

附件按所属合同展示名称、分类、上传人和时间。编辑时可以登记附件记录、移除或恢复已有记录；删除与恢复在保存时生效。

当前附件能力保存元数据，尚不能通过本功能下载或预览文件内容。选择本机文件并不代表文件原件已上传归档。

收票金额只累计已归档发票，支付金额只累计已确认支付的合同分摊。其他支出合同的结算累计来自真实已确认结算，变更后合同金额包含有效增补。公司支出合同不提供项目结算口径。缺失税率时无税金额和税额显示“未记录”。

## 五、从项目或分供方进入

其他支出合同详情中的项目、乙方分供方名称可进入对应只读详情。从项目或分供方页面的“其他支出合同”区域进入列表时，系统会限定该来源对象。

使用“返回来源”逐级返回。合同列表的搜索、筛选、页码，以及来源页签、位置和操作焦点会保留。无有效来源时返回该类合同列表。

## 六、异常与当前边界

| 状态 | 处理方式 |
| --- | --- |
| 暂无合同 | 有编辑权限时可点击新建 |
| 没有符合条件的合同 | 调整或清除筛选，不必重复建档 |
| 服务暂时不可用 | 点击重新加载；保存失败时保留输入后重试 |
| 无权限 | 页面不展示写入口；联系权限管理人员核实 |
| 合同不存在或来源不匹配 | 返回来源重新进入，不通过改 URL 更换合同类型 |

当前已可用范围为浏览器开发验证环境中的两类合同列表、只读详情、显式表单、附件元数据、票款投影和真实来源往返。中央端是可重置测试实例，重启服务可能清除测试实例记录，不应作为生产业务持久化交付。

其他支出结算的正式持久服务、已确认原费用采用、原件正文与完整历史迁入，见[专属结算指南](./other-expense-settlement.md)。本指南中的两类辅助合同仍沿其实际开发验证/Native owner；该合同来源尚未正式接通时，不能借测试实例打开生产合同结算。材料采购结算与外部审批按各自现行模块说明。旧本地数据须从真实原库导出一致快照，再到对应领域的迁入页逐条核验关系；不能靠改名称或金额合并身份。
