## 二、识别与人工归档边界（#253 已收口）

- 所有 OCR 结果先生成“待人工归档”草稿，不自动归档。
- 标准版式可以自动预处理；手写、低清、字段不足或非标准单据进入人工处理队列。
- 缺少单价或金额时，人工查看原件并确认送货事实后可以先归档；系统标记“价格待补录”，该行在补录并确认有效单价前不得进入价格分析。
- 数量×单价与金额不一致时标记“金额待复核”；人工确认并填写原因后才能归档。
- 供应商或日期缺失时不得自动补全；单号缺失可以人工确认后归档，并标记“原件无单号”。
- 每行材料的名称、单位和非零数量必须人工确认；相同文件只识别一次。

## 三、查看与筛选归档记录

1. 进入“材料管理 → 送货单归档库”。归档库只展示已经归档、可追溯的送货单记录；识别处理中记录仍在处理队列中。
2. 可选择项目树节点，输入送货单号、项目、分供方或原件文件名进行搜索。
3. 需要缩小时间范围时，填写开始日期和结束日期；筛选会同时作用于列表和后续导出。
4. 展开一条记录可查看该送货单下的材料、规格、单位、数量、单价和金额等明细。

## 四、导出送货单原件包

1. 先按项目、日期或关键词筛选出需要交付的记录。
2. 如需把 PNG/JPG 图片另行封装到一个 PDF，勾选“图片另生成 PDF”。该选项只处理图片，不处理 PDF 原件。
3. 点击“导出原件包”，系统下载当前筛选结果的 ZIP。
4. ZIP 固定包含 `送货单明细.xlsx` 和 `导出说明.txt`；原始 PDF 放在 `原件/PDF/`，原始图片放在 `原件/图片/`。勾选图片转换且存在可转换图片时，另有 `图片原件合并.pdf`。
5. Excel 按材料明细行展开，包含送货单号、日期、项目、分供方、材料、规格、单位、数量、单价、金额、原件文件和异常说明，并保留数值与日期格式。
6. 多页 PDF 和多张送货单共用的 PDF 都以原始字节整份保留；共用源只入包一次，不拆页、不重排、不伪造页码。缺少原件的记录会同时写入 Excel 异常说明和包内导出说明。

## 五、使用边界

- 当前没有安全且无需新增生产依赖的 PDF 对象级合并能力，因此不会把多份 PDF 合成一个新 PDF，也不会用 Canvas/JPEG 栅格化重建。真正保持原对象与页面结构的多 PDF 合并仍待后续实现。
- “图片另生成 PDF”只支持可安全渲染的 PNG/JPG。运行环境不支持图片渲染时会明确报错，不会把失败误报为已合并。
- 送货单识别结果仍需人工确认，OCR 只能提供候选字段，不替代原件核对。
- 如果原件未随记录保存，或一张送货单无法明确区分分供方，导出结果会在“异常提示”列标记；这类记录仍会导出，但不应直接作为最终结算依据。
- 文件夹整理和批量调整归档归属仍属于后续定稿功能；当前导出目录是固定保真结构，不是可配置的档案整理树。
