## 一、适用范围

本指南说明项目列表中的“导入项目”，以及历史地址 `/import/mapping/project` 的相同流程。#452 已在本机磁盘隔离工作区验证项目和导入回执跨独立进程重启保留，同一文件重复导入不增项目；边界见[本机项目指南](./local-project-storage.md)。备份恢复和正式启用仍按生产承接票验收，不能据此认定正式上线。

本次导入创建正式来源项目。顶部“包含测试数据”只影响查看范围；导入仍只使用当前可读的正式客户。历史整库迁移不属于本流程的已验收范围。

## 二、准备文件并选择工作表

1. 在项目列表点击“导入项目”。没有项目写权限时入口不可用；直接打开历史地址也必须通过中央权限校验。
2. 选择或拖入 Excel / CSV 文件。多 Sheet 文件需要选择本次要导入的 Sheet，再点击“使用此工作表”；空白 Sheet 会提示没有数据行。
3. 保留原始文件。系统记录文件名、内容摘要、Sheet、原始行号和解析后的源行快照；不会把整个 Excel 原件上传成项目附件。

文件中的标题、空行不会改变拒绝清单显示的原 Sheet 行号。请勿将合成验收样本当作真实业务资料。

## 三、核对列映射和客户

项目名称、客户、项目经理是必填项。系统按现行模板匹配列；请核对有疑问的匹配，必要时手工选列。点击“下一步”后会读取正式客户并生成预览；读取期间映射暂时锁定，失败可重试或取消。

| 核对项 | 操作说明 |
| --- | --- |
| 客户与次客户 | 可使用当前正式客户的稳定 ID，或可唯一识别的名称/别名；优先使用稳定 ID |
| 缺失、同名或停用客户 | 根据行级原因修正。次客户可不填，但填写后同样校验；不会自动创建客户 |
| 日期 | 使用有效日期，例如 2026-09-09；非法日期会拒绝 |
| 阶段 | 预览同时显示原始值和采用值；空值或未知值按当前导入规则归为“筹备中” |
| 外部旧 ID | 有旧系统标识时保留。它用于本 Excel 导入链路的成功回执防重，不自动覆盖现有项目 |

在人工预览中核对真实客户 ID、采用阶段及原始行。可以移除本次不想导入的行，或返回上一步修改映射。确认前不会保存项目。客户若在预览后被删除、停用或失去查看权限，中央提交会再次检查并逐行说明。

## 四、确认导入与查看结果

点击“开始导入”后逐行保存。成功必须取得中央项目 ID 并完成表单回读。全部成功会提示成功行数并返回项目列表；从项目名称进入详情，刷新仍从同一中央来源读取。

部分成功时保留结果页，显示成功数、未导入数、原始行号和拒绝原因。成功项目提供详情链接；可以下载拒绝清单，或返回项目列表查看已保存部分。未通过的一行不会阻止其他有效行保存。

## 五、失败、重试与取消

| 情况 | 下一步 |
| --- | --- |
| 客户资料或权限需要修复 | 完成修复后点击“重试未导入行”；客户身份在成功预览后固定为当时的 ID，不因改名改接其他客户 |
| 文件字段需要修改 | 修正文件后重新上传并预览；保留外部旧 ID 有助于识别已经成功的行 |
| 提交响应丢失或回读失败 | 当前行显示“尚未确认完成”；直接重试，系统复用原命令并回读已保存项目 |
| 完全相同的原文件重传 | 同一 Sheet、原始行和相同内容返回原项目 ID，成功行不会重复创建 |
| 已保存外部旧 ID 的内容不同 | 显示冲突，导入不会覆盖项目；需要修改时从项目详情显式进入编辑 |
| 导入前取消 | 返回列表，不保存任何行 |
| 导入中停止 | 显示“等待当前行结束”，当前行结束后返回列表，后续行停止；原文件重传可继续处理剩余行 |

重新制作文件会改变文件摘要；没有外部旧 ID 时，系统不能认定新文件中的行与旧文件是同一项目。外部旧 ID 防重仅覆盖本 Excel 流程已保存的回执，不核对历史整库迁移映射，也不按项目名称合并项目。

切换顶部数据来源会要求确认并重新加载应用，未保存的选择和预览随之清空；取消确认可继续当前操作。刷新导入页也需重新选择文件。已成功保存的行仍由中央回读；原文件、Sheet 和行号可用于安全重试。

## 六、当前边界与后续验收

当前已验证：真实文件解析、选 Sheet、映射、预览、逐行中央保存、部分成功与重试、客户失效与权限拒绝、列表详情刷新、取消与来源切换。

待后续验收：生产数据库实际部署、服务重启后的持久保存和备份恢复。完整审批引擎、自动合并旧项目及历史迁移旧 ID 匹配不由本导入流程补造。

规则依据：项目页面规格、中央写命令契约、数据库导入追溯规则及 ADR 0020；开发入口见 docs/README.md。
