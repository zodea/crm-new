# 送货单识别、归档与原件处置需求

> 2026-09-08 的需求范围继续保留；原六阶段移植方案已退出当前实施规格，历史背景通过[固定 Git 来源](https://github.com/zodea/crm-new/blob/c16869fcbf954dddd46143839afe5790f3828f1a/docs/research/invoice-recognition-app-port-plan.md)定位。
>
> 当前工作由[附件、OCR 与 Excel #406](https://github.com/zodea/crm-new/issues/406)和[物资归档与价格 #411](https://github.com/zodea/crm-new/issues/411)承接。本页保留产品需求与待核实能力，不声明已实现，不另立字段、状态或技术选型。

## 当前流程与权威入口

送货识别在乙供材管理，发票识别在资金管理，不恢复独立“识别中心”导航组。送货处理区和归档库分开；完整页面规则以[送货蓝本](../rewrite/pages/material-delivery.md)为准。

1. **上传队列**：先上传受支持原件并展示真实进度，不因未选项目提前拦截；一份物理原件可能含多张逻辑单据。
2. **识别与人工校对**：OCR 生成待核对草稿；保留原件、识别值与人工修订，低置信、识别失败、归属冲突和金额不平各有恢复路径。
3. **人工归档与回读**：核对完成后明确归属并执行归档。归档形成送货事实，有效到货、库存与价格资格分别校验；物资规则见[物资蓝本](../rewrite/pages/material-management.md)。
4. **原件处置**：新归档保留待打印任务；实际打印后的明确回执、手动排除分别记录。导出生成实际文件并如实报告结果，不影响业务资格。

批量整理树、独立分区与常驻六阶段步骤条是旧候选设计，不能据旧故事重新建一套流程；适用价值与具体差异由 #411 联同 #406 调查，已有决定优先。

## 已定异常与关系边界

异常、必填、无单号例外、缺价格、更正与打印处置只维护在[送货页面](../rewrite/pages/material-delivery.md)；有效到货、库存和结算资格只维护在[物资页面](../rewrite/pages/material-management.md)，稳定关系、迁入及价格来源见 [DATABASE](../rewrite/DATABASE.md)。本 PRD 只要求这些边界形成可演示、可恢复的用户流程，不保存第二份规则表，也不据旧待确认分供方描述放宽新归档的当前资格。

公共幂等、权限、版本、回执和保存后回读直接执行 [COMMANDS](../rewrite/COMMANDS.md)与 [READ-MODELS](../rewrite/READ-MODELS.md)。页面复核仍需覆盖原件缺损、无法证明的关系、重复操作、再次识别与更正，不以归档标记替代下游来源验证。

## 交互能力的逐项复核

- 文件队列、原图与字段同屏校对；保持选中项、草稿、滚动和错误定位。
- 材料行的名称、规格、单位、数量、单价、金额及服务项分类按页面/数据权威逐项核对；人工金额不被自动计算悄悄覆盖。
- 置信度同时使用文本或图标，不能只依赖颜色；无坐标时保留可用校对，不伪造字段高亮。
- 字段与原图联动、逐格键盘编辑、复制粘贴、行增删及失败重试按现有能力核验。
- 手动拖网格线转录、批量文件夹整理、分区、旋转重试、跨页合单及映射记忆只保留为待核实能力；#406/#411 先查已有决定、实现和收益，再形成可执行任务。
- 归档库采用项目—分供方树及真实列表；筛选、分页、来源下钻和返回一致，未区分分供方节点不伪装成有效主档。
- 价格分析只读取满足有效门槛且有人工确认价格的归档材料行，运费等非材料项与材料报价分开，不另存第二份价格事实。
- 同类稳定交互复用现有原语；领域工作台保留自身流程，不按旧“全部底座完成后再做 UI”顺序排期。

## OCR、保存和输出边界

引擎、运行模式、预处理和配置执行 [ADR 0006](../adr/0006-ocr-paddleocr-vl-single-model.md)。官方联网模式需用户显式启用，不能静默上传或自动回退；Access Token 仅在服务端私有配置，浏览器只显示配置状态。OCR 始终有人工核对。

保存与回读按 [ADR 0020](../adr/0020-browser-authority-and-demo-workspace-boundary.md)：已接管实体只走中央命令与查询，过渡本地适配不能成为正式回退。当前前台验证与后置生产持久化、服务重启、备份恢复及部署分开验收。

原件包、Excel 与可选图片 PDF 执行 [ADR 0019](../adr/0019-delivery-export-source-preservation.md)，不把逻辑拆单或预览派生图当作原件。多份 PDF 的对象级保真合并仍需复核实现，不能把 ZIP 或图片合并当作该功能已完成。

导出执行 [ADR 0004](../adr/0004-export-interaction-model.md)：直接保存按浏览器能力可使用普通下载；需要目录结构的配置导出不能用普通下载伪报成功。取消目录选择安静返回，失败保留可重试位置，成功以实际文件为证。

## 验收与实施承接

按[模块复核规程](../agents/module-review.md)，每项列出当前证据、目标结果、来源变化、失败/重复/更正路径与验收例。保留解析、身份匹配、冲突合并、价格归组等行为测试；主干旅程覆盖上传、人工核对、归档读回、有效资格、价格及原件处置。文件实际回读、四档视口、键盘焦点与浮层边界分别验收。
