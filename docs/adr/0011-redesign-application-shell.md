# 重做应用外壳：紧凑导航、动作顶栏、路由页签与通知中心

> 状态：已采纳（2026-07-13）
> 来源：GitHub Issue #82 的最新验收口径；交互底座继续遵循 ADR 0008。

旧应用外壳混用了毛玻璃侧栏、中文单字方块、双行顶栏和演示性动作。它既压缩了高频 CRM 导航的信息密度，也让真实路由、缓存、通知与响应式行为缺少统一所有者。

**决策**：应用外壳采用紧凑、路由驱动的 CRM 工作台结构：

- 桌面侧栏展开宽度 248px、收起轨道 68px；默认固定展开。取消固定后，主内容保持 68px 偏移，侧栏可临时悬浮展开。固定状态、主题和分组展开状态写入本地存储。
- 导航使用 16px Lucide 图标与单行名称；所有真实叶子保持可导航，尚未接通的入口保持禁用。允许多组同时展开，当前路由所属组自动展开，并提供名称/提示搜索。
- 侧栏深蓝/浅色主题只影响外壳，通过 `--shell-*` 令牌桥接现有 shadcn 语义令牌，不改变业务内容区主题。
- 顶栏高度 54px，只承载移动端导航入口、主题、通知和开发期真实入口；不展示伪标题、伪搜索、日期或用户动作。
- 页签栏高度 36px，页签由路由唯一标识，保留右键四类关闭动作；刷新仅使当前页签实例与滚动缓存失效，关闭页签同步清理缓存记录，最多保留 15 个业务页签。
- 通知中心为右侧 390px 抽屉，通知数据归 Pinia store 所有；支持待办/通知分栏、关键词与类型筛选、已读、全部已读、删除和点击真实路由。
- 顶栏与页签固定，仅业务内容区滚动；内容最大宽度 1480px。小于 1024px 时侧栏改为 reka-ui Dialog Sheet。

**边界**：

- 侧栏响应式与移动端焦点管理复用 ADR 0008 的 shadcn-vue / reka-ui 底座。
- 页签转移、关闭顺序仍以纯状态机为权威；组件只负责路由和呈现。
- ADR 0007 继续约束业务内容区圆角卡片风格，不再约束应用外壳。

**后果**：`docs/rewrite/DESIGN-SYSTEM.md`、`docs/rewrite/CRM-PATTERNS.md` 中关于“中文单字方块 + 毛玻璃侧栏”的条款过时；这些文档只保留为历史设计资料，新的外壳实现与评审以本 ADR 为准。
