# 重做应用外壳：紧凑导航、动作顶栏、路由页签与通知中心

> 状态：已采纳（2026-07-13）；**⚠️ 视觉与布局条款已被 [ADR 0013](0013-align-all-ui-to-online-design.md) 取代**。本 ADR 的早期方案以及此后曾转述的白底宽侧栏、双行导航方案均仅供历史溯源；当前外壳样式、尺寸及双源权威边界统一看 ADR 0013 的最新裁定。本文**行为能力条款继续有效**（下文逐条标注 ⛔=历史视觉作废 / ✅=行为保留）。
> 初始决策来源：GitHub Issue #82；交互底座继续遵循 ADR 0008。

旧应用外壳混用了毛玻璃侧栏、中文单字方块、双行顶栏和演示性动作。它既压缩了高频 CRM 导航的信息密度，也让真实路由、缓存、通知与响应式行为缺少统一所有者。（历史背景：「中文单字方块」曾随 ADR 0013 的白底侧栏方案回归，该中间方案现已被 ADR 0013 的后续裁定覆盖。）

**决策**：应用外壳采用紧凑、路由驱动的 CRM 工作台结构：

- ✅ 桌面侧栏默认固定展开；取消固定后，主内容保持收起轨道对应的偏移，侧栏可临时悬浮展开。固定状态和分组展开状态写入本地存储；展开/收起尺寸由 [ADR 0013](0013-align-all-ui-to-online-design.md) 定义（⛔ 原「主题」持久化随深蓝/浅色双主题一并作废，不因当前深色外观恢复主题切换）。
- ⛔ ~~导航使用 16px Lucide 图标与单行名称~~（本 ADR 的历史配方及中间版本的单字方块、副提示方案均不再作实施目标；现行导航规则看 [ADR 0013](0013-align-all-ui-to-online-design.md)）；✅ 所有真实叶子保持可导航，尚未接通的入口保持禁用。允许多组同时展开，当前路由所属组自动展开，并提供名称/提示搜索。
- ⛔ ~~侧栏深蓝/浅色主题只影响外壳~~（历史双主题方案已作废）；✅ `--shell-*` 令牌桥接机制保留，颜色映射按 [ADR 0013](0013-align-all-ui-to-online-design.md) 的现行规则维护。
- ⛔ ~~顶栏高度 54px，不展示伪标题、伪搜索、日期或用户动作~~（历史视觉已作废；尺寸、标题和日期布局看 [ADR 0013](0013-align-all-ui-to-online-design.md)）；✅ 顶栏承载移动端导航入口、通知与开发期真实入口。
- ✅ 页签由路由唯一标识，保留右键四类关闭动作；刷新仅使当前页签实例与滚动缓存失效，关闭页签同步清理缓存记录，最多保留 15 个业务页签。页签溢出时提供显式向前/向后翻屏按钮，鼠标滚轮、活动页签自动进入视口和键盘焦点继续可用。⛔ ~~页签栏高度 36px、Chrome 式连接页签（顶部圆弧、内凹肩线）~~（历史视觉已作废；尺寸及活动态看 [ADR 0013](0013-align-all-ui-to-online-design.md)）。
- ⛔ ~~外壳一级导航与路由页签使用 14px 字号~~（历史字阶已作废；当前排版看 [ADR 0013](0013-align-all-ui-to-online-design.md)）；✅ 品牌蓝只用于选中、聚焦与关键操作。
- ✅ 通知中心在 1024px 及以上为右侧 390px Sheet，在 768px 及以下退化为带把手的底部 Sheet；通知数据归 Pinia store 所有，支持待办/通知分栏、关键词与类型筛选、已读、全部已读、删除和点击真实路由。两种形态都由 reka-ui 管理 Esc、焦点陷阱与焦点返回，并通过应用浮层栈锁定工作区滚动。
- ✅ 顶栏与页签固定，仅业务内容区滚动；小于 1024px 时侧栏改为 reka-ui Dialog Sheet。⛔ ~~内容最大宽度 1480px~~（历史尺寸已作废；内容留白与响应式布局看 [ADR 0013](0013-align-all-ui-to-online-design.md)）。

**边界**：

- 侧栏响应式与移动端焦点管理复用 ADR 0008 的 shadcn-vue / reka-ui 底座。
- 页签转移、关闭顺序仍以纯状态机为权威；组件只负责路由和呈现。
- ADR 0007 继续约束业务内容区圆角卡片风格，不再约束应用外壳；**外壳视觉现由 ADR 0013 定义**。

**后果**：外壳的行为实现与评审以本 ADR 为准，**视觉与布局评审以 [ADR 0013](0013-align-all-ui-to-online-design.md) 为准**。本 ADR 的早期视觉与此后转述的中间方案均保留为被覆盖的历史记录，不再维护另一套现行尺寸或颜色快照。
