# 重做应用外壳：紧凑导航、动作顶栏、路由页签与通知中心

> 状态：行为决定有效；视觉与布局已由 [ADR 0013](0013-align-all-ui-to-online-design.md) 取代。原决策采纳于 2026-07-13，来源 #82；旧视觉方案见 Git 历史。

**决策**：应用外壳采用紧凑、路由驱动的 CRM 工作台结构：

- 桌面侧栏默认固定展开；取消固定后，主内容保持收起轨道对应的偏移，侧栏可临时悬浮展开。固定状态和分组展开状态写入本地存储；展开/收起尺寸由 [ADR 0013](0013-align-all-ui-to-online-design.md) 定义；不恢复已退役的深蓝/浅色主题切换。
- 所有真实叶子保持可导航，尚未接通的入口保持禁用。允许多组同时展开，当前路由所属组自动展开，并提供名称/提示搜索。
- `--shell-*` 令牌桥接机制保留，颜色映射按 [ADR 0013](0013-align-all-ui-to-online-design.md) 的现行规则维护。
- 顶栏承载移动端导航入口、通知与开发期真实入口。
- 页签由路由唯一标识，保留右键四类关闭动作；刷新仅使当前页签实例与滚动缓存失效，关闭页签同步清理缓存记录，最多保留 15 个业务页签。页签溢出时提供显式向前/向后翻屏按钮，鼠标滚轮、活动页签自动进入视口和键盘焦点继续可用。
- 品牌蓝只用于选中、聚焦与关键操作。
- 通知中心在 1024px 及以上为右侧 390px Sheet，在 768px 及以下退化为带把手的底部 Sheet；通知数据归 Pinia store 所有，支持待办/通知分栏、关键词与类型筛选、已读、全部已读、删除和点击真实路由。两种形态都由 reka-ui 管理 Esc、焦点陷阱与焦点返回，并通过应用浮层栈锁定工作区滚动。
- 顶栏与页签固定，仅业务内容区滚动；小于 1024px 时侧栏改为 reka-ui Dialog Sheet。

**边界**：

- 侧栏响应式与移动端焦点管理复用 ADR 0008 的 shadcn-vue / reka-ui 底座。
- 页签转移、关闭顺序仍以纯状态机为权威；组件只负责路由和呈现。
- ADR 0007 继续约束业务内容区单层容器，不再约束应用外壳；**外壳视觉现由 ADR 0013 定义**。

**后果**：行为按本 ADR 验证，视觉与布局直接查 ADR 0013，不再保留另一套现行尺寸或颜色快照。
