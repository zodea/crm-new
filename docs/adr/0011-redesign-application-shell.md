# 重做应用外壳：紧凑导航、动作顶栏、路由页签与通知中心

> 状态：已采纳（2026-07-13）；**⚠️ 视觉与布局条款已被 [ADR 0013](0013-align-all-ui-to-online-design.md) 取代（2026-07-17，2026-07-27 按 #181 更新）**——有直接对应页时按严格只读的运行参考收敛构图与密度；线上设计稿 `app.dc.html` 保留瑞航品牌、DC 独有能力和无直接参考页的外壳方案（白底浅色侧栏 + 64px 白顶栏 + 40px 红圈式页签）。本文**行为能力条款继续有效**（下文逐条标注 ⛔=视觉作废 / ✅=行为保留）。
> 来源：GitHub Issue #82 的最新验收口径；交互底座继续遵循 ADR 0008。

旧应用外壳混用了毛玻璃侧栏、中文单字方块、双行顶栏和演示性动作。它既压缩了高频 CRM 导航的信息密度，也让真实路由、缓存、通知与响应式行为缺少统一所有者。（历史背景：其中「中文单字方块」后随 ADR 0013 以白底侧栏形态回归，毛玻璃侧栏仍废弃。）

**决策**：应用外壳采用紧凑、路由驱动的 CRM 工作台结构：

- ✅ 桌面侧栏展开宽度 248px、收起轨道 68px；默认固定展开。取消固定后，主内容保持 68px 偏移，侧栏可临时悬浮展开。固定状态和分组展开状态写入本地存储（⛔ 原「主题」持久化随深蓝/浅色双主题一并作废——ADR 0013 后外壳仅浅色）。
- ⛔ ~~导航使用 16px Lucide 图标与单行名称~~（视觉作废：按 ADR 0013 导航项 = 中文单字方块 mark + 名称 + hint 副提示，Lucide 图标仅组头 15px）；✅ 所有真实叶子保持可导航，尚未接通的入口保持禁用。允许多组同时展开，当前路由所属组自动展开，并提供名称/提示搜索。
- ⛔ ~~侧栏深蓝/浅色主题只影响外壳~~（视觉作废：外壳仅白底浅色）；✅ `--shell-*` 令牌桥接机制保留，值按 ADR 0013 重映射浅色。
- ⛔ ~~顶栏高度 54px，不展示伪标题、伪搜索、日期或用户动作~~（视觉作废：按 ADR 0013 顶栏 64px 白底 blur(8px)，左侧页标题 18/800 + 副标 12，右侧日期）；✅ 顶栏承载移动端导航入口、通知与开发期真实入口。
- ✅ 页签由路由唯一标识，保留右键四类关闭动作；刷新仅使当前页签实例与滚动缓存失效，关闭页签同步清理缓存记录，最多保留 15 个业务页签。⛔ ~~页签栏高度 36px、Chrome 式连接页签（顶部圆弧、内凹肩线）~~（视觉作废：按 ADR 0013 为 40px 红圈式页签栏，`--surface-2` 底，active = 白底 + brand 字 + inset -2px 下划线，上圆角 6px）。
- ⛔ ~~外壳一级导航与路由页签使用 14px 字号~~（视觉作废：设计稿实测 13/600）；✅ 品牌蓝只用于选中、聚焦与关键操作。
- ✅ 通知中心为右侧 390px 抽屉，通知数据归 Pinia store 所有；支持待办/通知分栏、关键词与类型筛选、已读、全部已读、删除和点击真实路由。
- ✅ 顶栏与页签固定，仅业务内容区滚动；小于 1024px 时侧栏改为 reka-ui Dialog Sheet。⛔ ~~内容最大宽度 1480px~~（布局尺寸以 ADR 0013/镜像实测为准，内容区 padding `20px 24px 36px`）。

**边界**：

- 侧栏响应式与移动端焦点管理复用 ADR 0008 的 shadcn-vue / reka-ui 底座。
- 页签转移、关闭顺序仍以纯状态机为权威；组件只负责路由和呈现。
- ADR 0007 继续约束业务内容区圆角卡片风格，不再约束应用外壳；**外壳视觉现由 ADR 0013 定义**。

**后果**：`docs/rewrite/DESIGN-SYSTEM.md`、`docs/rewrite/CRM-PATTERNS.md` 中「毛玻璃侧栏」条款仍过时；「中文单字方块」已按 ADR 0013 回归。外壳的行为实现与评审以本 ADR 为准，**视觉与布局评审以 ADR 0013 为准**。
