# 送货单导出的原件保真与可选转换

> 状态：已采纳（2026-08-10；关联 Issue #23）

送货单导出包采用线上直接下载的 ZIP，至少包含按统一排序生成的 Excel 明细和合并 PDF。单页 PDF 或图片只做保持原比例的 PDF 页面封装；只有识别出页面方向明显错误时才旋转，不叠加 OCR 或业务排版。多页 PDF、多个送货单共用的 PDF 整份原样保留，不拆分、不重排、不伪造页码；同一共用原件只进入 PDF 一次。图片默认保留原格式，只有用户勾选“将图片原件转换为 PDF 页面”时才加入合并 PDF，未勾选时放入 ZIP 的 `原件/图片/`。本 Issue 不做目录配置，后续需要时沿用 [ADR 0004](0004-export-interaction-model.md) 的配置导出路径。

> 当前实现说明（2026-08-11）：在尚无安全、无新增生产依赖的 PDF 对象级合并能力时，ZIP 已将每份 PDF 原件以原始字节整份保存在 `原件/PDF/`，共用源只入包一次；绝不通过 Canvas/JPEG 栅格化重建。用户勾选图片转换时，系统另行生成只含 PNG/JPG 图片的 `图片原件合并.pdf`，不包含 PDF 原件。多份 PDF 真正保持原对象与页面结构的合并仍待后续依赖选型和实现，因此当前交付不得称为“所有原件已合并 PDF”。
