# 送货单导出的原件保真与可选转换

> 状态：已采纳（2026-08-10；关联 Issue #23，当前为部分落地，不表示 Issue 已完成）

## 当前导出合同

送货单原件包通过 [ADR 0004](0004-export-interaction-model.md) 的 `direct-save` 路径导出 ZIP。ZIP 包含按统一排序生成的 `送货单明细.xlsx`，以及本次能够取得的原始原件；缺少原件的记录必须在 Excel 和导出说明中留痕。

PDF 原件以原始字节整份保存在 `原件/PDF/`，多页 PDF 不拆分、不重排、不栅格化重建；多个送货单共用同一源文件时，ZIP 只保存一份。PNG/JPG 图片默认以原格式保存在 `原件/图片/`。只有用户勾选“图片另生成 PDF”时，系统才额外生成只包含这些图片的 `图片原件合并.pdf`；该文件不包含 PDF 原件，也不应被描述为“所有原件的合并 PDF”。

## 尚未实现的边界

多份 PDF 在保持原始 PDF 对象、页面结构和原始字节语义前提下的对象级合并，仍待后续依赖选型与实现。当前导出合同不要求 ZIP 必含合并 PDF，#23 在该能力完成前保持未完成状态。
