# 变更单已签证自动生成变洽签台账行

> 状态：已采纳（2026-07-05）

「变更」有两个实体：清单页的变更单（量价明细，驱动量差/产值）与项目详情 Tab③ 的甲方变洽签（金额台账，驱动「变更后合同额」）。红圈里两边独立手录；但单项目变更单可达 200 份（未来印工程实测量级），双录必然跑偏——清单加了变更量、台账忘登，经营数据就少一块。

**决策**：变更单状态机走到**已签证**（四档：草稿→已上报→已打回→已签证）那刻，自动生成一行变洽签台账行，**一对一**、带来源追溯键（用户明确要求能匹配到是哪个变更单）、金额=Σ变更行合价。纯金额签证（工期索赔等无量价明细）仍可在 Tab③ 手录，台账=自动行+手录行的合集。

**考虑过的替代**：完全独立（红圈原样，被双录风险否决）；彻底合一（纯金额签证强拆量价，不现实，被否决）。

**后果**：变洽签台账的自动行不可直接改金额——改量价须回到来源变更单；删除已签证变更单需级联处理台账行（软删除联动）。
