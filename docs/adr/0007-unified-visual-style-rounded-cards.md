# 统一视觉风格：内容层级单轨，废弃旧式扁平 CRM 拼装

> 状态：已采纳（2026-07-05）；形状与阴影条款由 [ADR 0013](0013-align-all-ui-to-online-design.md) 2026-07-27 补充裁定更新
> 影响：`docs/rewrite/DESIGN-SYSTEM.md` §1.2/§3.2/§4.1、`docs/rewrite/CRM-PATTERNS.md` §7/§8 的「内容区扁平」条款作废，改以本 ADR 为视觉基准。
> ⚠️ 2026-07-27：本文继续约束**业务内容区的单层容器语言**；12px 圆角、卡片阴影和 pill 搜索框已被 ADR 0013 的小圆角无阴影裁定取代。外壳视觉与全站布局/排版/颜色基准也见 ADR 0013；ADR 0011 仅存外壳行为条款。

早期设计文档照搬红圈 CRM 的**扁平企业风**：内容区无圆角、无阴影、纯 1px 边框（DESIGN-SYSTEM.md §1.2「双层风格」、§3.2；CRM-PATTERNS.md §7）。但用户实际调到满意的首页（`DC重构设计源码/kit/HomeScreenNew.jsx`）与工程量页（`QuantityScreenV2.jsx`）走的是**圆角卡片 + 阴影的现代 SaaS 仪表盘风**。其余页面若照旧扁平 docs 做，会与已定稿的首页割裂、观感各做各的。2026-06-30 曾临时决定「docs 暂不同步、直接按新风做」，结果 docs 与实现长期背离——这类背离正是维护成本的来源。

**决策**：统一视觉基准 = **小圆角描边面板 + 无卡片阴影的紧凑工作台**，以现有模块结构为样板，覆盖全部内容区页面；不回到无边界拼装，也不再靠大圆角和浮层感区分普通内容：

- 面板容器：白底 `var(--panel)` + `1px solid var(--line)` + 圆角 `var(--radius-card)`（4px）+ 无卡片阴影，内 padding 12–16px；可点面板只变边框或底色，不上浮。
- 区块标题 14px/700；指标数字 22px `--font-mono`/700，label 12px/600 灰，备注 11px faint。
- 按钮 / 输入圆角 `var(--radius-btn)`（4px），小型图标/分页控件用 `var(--radius-sm)`（3px）；pill 只用于状态、计数和进度等明确语义，搜索和筛选使用小圆角矩形。业务内容分段 Tab 仍为下划线式，应用外壳路由页签视觉由 ADR 0013 定义（行为归 ADR 0011）。
- 品牌色仍以 `#3976C6` 为锚点；中性色改为冷蓝灰阶，正文基准 ~~15px~~（**勘误 #110/A1**：权威令牌 `typography.css --text-base:14px`、`tokens.css html{font-size:14px}` 与设计稿实测均为 **14px**，以 14px 为准；工具栏控件/tab 阶为 13px）、表格正文 14px，保证高频扫读时的对比与可读性。
- 数据表格由 4px 圆角面板承载，表头/数据行均为 38px；表头 13px/700、正文 14px，单元格水平留白 6px。
- **应用外壳不在本 ADR 范围内**：侧边栏、顶栏、页签视觉由 ADR 0013 定义，页签状态机/通知抽屉等行为由 ADR 0011 定义。全套 v5 业务内容色值（品牌/状态/文字/基底）不变。

**考虑过的替代**：直接复制红圈品牌色、导航和业务结构——会破坏瑞航已定布局与颜色，否决；保留 12px 大圆角和卡片阴影——与用户 2026-07-27 指定的当前参考界面不一致，否决。

**后果**：
- DESIGN-SYSTEM.md / CRM-PATTERNS.md 的扁平条款需标注废弃并指向本 ADR（红圈截图里的**布局模式**——面包屑 Tab、列组切换、详情 70/30、审批时间线等——仍然有效，作废的只是"扁平形状"）。
- `--shadow-card` 保留变量名以兼容既有组件，但普通内容面板解析为 `none`；浮层仍使用独立的 `--shadow-pop`。
- CRM-PATTERNS.md 中“无边界拼装”与“大圆角悬浮卡片”两类旧形状描述均由本 ADR 和 ADR 0013 的小圆角描边面板取代。
