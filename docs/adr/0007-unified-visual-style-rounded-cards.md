# 统一视觉风格：业务内容区单层容器

> 状态：有效；圆角、阴影、字阶与表格密度等视觉参数已由 [ADR 0013](0013-align-all-ui-to-online-design.md) 更新。原决策采纳于 2026-07-05，旧方案由 Git 历史保留。

**决策**：业务内容区采用统一的单层容器语言，以小圆角描边面板组织内容；避免无边界拼装和重复嵌套卡片。应用外壳视觉归 ADR 0013，外壳行为归 [ADR 0011](0011-redesign-application-shell.md)。

- 普通内容面板无卡片阴影，可点面板只改变边框或底色，不上浮。
- 内容区未被后续裁定替代的细节保留：面板内边距 12–16px；区块标题 14px/700，指标数字 22px `--font-mono`/700，label 12px/600 灰、备注 11px faint。具体组件有更新契约时以其现行规格为准。
- `--shadow-card` 保留名称兼容既有组件，普通内容面板解析为 `none`；浮层使用独立的 `--shadow-pop`。
- 参考系统的页面布局模式可按实际业务采用，品牌、颜色和控件几何遵守 ADR 0013；不复制参考系统的业务结构。

**权衡**：统一容器层级减少页面各自拼装；早期大圆角、卡片阴影和 pill 搜索框方案已被后续裁定替代，不再作为实施参数。

**后果**：[DESIGN-SYSTEM](../rewrite/DESIGN-SYSTEM.md) 不维护旧形状配方；具体尺寸、令牌和组件状态直接查 [ADR 0013](0013-align-all-ui-to-online-design.md) 与 [KitUI 组件规格](../design/kit-ui-component-specs.md)。
