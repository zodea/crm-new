## 一、定位与核心决策

作为**施工方**做整个工程的进度把控与成本控制。红圈 API 偏合同/材料台账（甲方成本视角），本模块补齐施工方最缺的一环：**把"计划工期"和"现场实际工程量"绑在同一条时间线上，随施工实时看提前/延后与成本偏差**。

核心原则（grill 已定）：

1. **一条时间线**：计划里程碑/工序 + 实际工程量推进 + today 线，叠在同一横轴（旬/月），不再头部一个时间节点、下面一个只读展示。
2. **工序挂计划，进度取阶段完成**：工序维护计划起止/工期/依赖，并引用稳定工序阶段；有工程量来源的工序按户 × 工序阶段完成事实**自动**算，不能从责任配置或分项共享完成率推断；无工程量来源的工序手动填。
3. **分组级一根条 + 下钻**：甘特按 `楼栋分组 × 工序阶段` 每格一根条 + 完成率；点工序下钻到工程量矩阵（筛到该分组 + 该阶段及映射分项）。
4. **成本双层**：首页项目级 目标 vs 实际；下钻工序时挂到分项、与材料联动。
5. **机械费**：设备租赁归支出合同/其他合同，作机械费科目归集，不单独建模块。

## 二、WBS 三层结构

照 PDF 规范，排程是三层 WBS：

```
项目（合和新城7期精装修工程 · 184 工作日 · 2026-05-01~10-31）
├── 楼栋分组 户内10栋-22栋（summary · 171 工作日）
│   ├── 工序 放线及新建墙体（30 工作日 · 5/6~6/4）
│   ├── 工序 给排水安装（30 工作日 · 5/8~6/6）
│   ├── … 22 道工序 …
│   └── 工序 开荒保洁（8 工作日 · 10/16~10/23）
└── 楼栋分组 户内23栋-30栋（summary · 149 工作日）
    └── … 同 22 道工序，计划错后 …
```

- **项目行 / 楼栋分组行**：summary，工期与起止由子工序汇总（min 开始、max 完成），不单独录。
- **工序行**：排程原子单位，人工录计划或从工序标准库带出。
- **楼栋分组**：跨多栋楼的分段（10-22栋 = 13 栋）。一个分组可选择多栋楼，关联模型见 `DATABASE.md`。

- 自动进度工序必须选择一个稳定工序阶段；手动进度工序不要求阶段来源。
- 同一工程量分项可供多个工序阶段读取适用范围，但各阶段的完成率和完成日期仍独立。
- 排程只读工程量域的完成结果，不提供第二个阶段完成录入口。

## 五、进度计算（计划 vs 实际）

### 5.1 自动进度工序的实际完成率

某工序（如 10-22栋·墙砖粘贴）的实际完成率 =
```
该分组所有楼栋下，该工序阶段【已完成户数】
÷ 该工序阶段在该分组的【总应做户数】
```
完成事实来自工程量域，不新增排程录入口。总应做户数由该工序与户型模板的分项适用范围圈定；若阶段不依赖计量分项，则该任务必须改为手动进度。

- 实际开始取该阶段在分组内最早完成日期；实际完成取全部应做户完成时的最晚完成日期。
- 尚未全部完成时不显示实际完成日期，进度线画到“当前完成率”处。
- 墙砖/地砖、一遍/二遍腻子分别使用各自工序阶段；即使映射同一个计量分项，也不得共享完成率。

### 5.2 手动进度工序

放线/给排水/电线/空调/门/柜/开关/洁具/保洁等无计量口径的工序，在工序行或弹窗直接填 0~100%。

### 5.3 提前/延后

```
计划应完成率 = clamp((today - plannedStart) / (plannedFinish - plannedStart), 0, 1)
偏差 = 实际完成率 − 计划应完成率
偏差 > 0 → 提前；< 0 → 延后；换算天数 = 偏差 × 工期
```
分组行、项目行的偏差按子工序**工期加权**汇总。

## 六、成本对比（目标 vs 实际 · 人材机）

### 6.1 首页 · 项目级

| 科目 | 目标（预算） | 实际（发生） |
|---|---|---|
| 人工 | 目标成本清单·人工 | 分包结算 + 零星用工结算（劳务分包/计件计时工资） |
| 材料 | 目标成本清单·材料 | 材料采购结算（乙供材+甲供材）+ 送货单 |
| 机械 | 目标成本清单·机械 | 设备租赁结算 + 零星机械结算 |
| 其他 | 目标成本清单·其他 | 费用报销 + 其他支出 |
| **合计** | 目标成本总额 | 累计支出 |

对比呈现：目标 vs 实际 双色柱 + 偏差率；结合进度算**已完成产值 vs 已发生成本**（挣值/成本超支预警）。

### 6.2 下钻 · 工序→分项级（与材料联动）

点工序进入工程量矩阵后，该分项每格（房间×分项）可展开：
- **人工**：该房间该分项施工人的工资（工程量 × 分项单价）。
- **材料**：该分项对应的材料消耗（送货单/领用挂到分项）——这是"与材料联动"的落点，需 `送货单/材料领用` 增加 `itemName` 归集维度。
- **机械**：分摊（若该工序用到设备租赁，按面积/工期分摊）。
- 目标：分项目标单价 × 工程量；实际：三项之和；差 = 盈亏。

> 材料联动为二期深化（送货单/领用增加分项归集字段），首期先打通 人工 + 进度，材料/机械先到项目级。

## 九、验收要点

1. 首页只有**一张**时间线，计划工序 + 实际完成率 + today 线同屏可见，能一眼看提前/延后。
2. 工序进度：自动进度按工序阶段聚合户完成率，手动进度直接填；同工种不同阶段互不串值。
3. 点任一工序能下钻到工程量矩阵并筛到对应分组+分项。
4. ~~首页项目级 目标 vs 实际（人材机）成本对比可见。~~ **作废（反馈轮 8）**：首页不放成本对比，对比看工程量清单。
5. 独立进度页可编辑 WBS：调计划、连依赖、套工序模板建分组。
6. 楼栋分组跨多栋，与工程量树的楼栋关联正确。
7. 工序标准库 22 道可作模板复用，分项映射可调。
