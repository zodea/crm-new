# 收款与往来收付 — 实际资金流入/非合同往来

> 表单蓝本：`receiptForm`、`currentForm`
> 持久化权威：`DATABASE.md` 的 `receipt_registrations` / `current_transactions`

## 一、收款登记

| 分区 | 字段与规则 |
|---|---|
| 基本信息 | 收款单号、收款日期*、项目*、施工合同（项目级联）、付款方客户*、付款方账号 |
| 金额与方式 | 收款金额*、收款方式、承兑汇票号、汇票到期日、收款期次、银行流水号 |
| 合同情况 | 变更后合同金额、合同累计收款、收款/合同占比、开票未收款；全部只读派生 |
| 凭证附件 | 收款回单、其他附件 |
| 经办与备注 | 经办人、审核状态、备注 |

项目、施工合同和付款方客户均保存真实 ID。收款金额是资金流入事实；合同累计收款从有效收款登记聚合，不回写合同静态金额。

## 二、往来收付

| 分区 | 字段与规则 |
|---|---|
| 基本信息 | 单据编号、收付方向*、项目*、往来方*、款项性质 |
| 金额与方式 | 金额*、收付方式、日期*、银行流水号 |
| 经办与备注 | 经办人、备注、凭证附件 |

收与付共用一个列表和表单，方向作为稳定业务字段保存。非合同往来不得混入合同收款或支付记录；资金汇总按方向分别计入。

## 三、验收

1. 合同级联只展示所选项目的施工合同。
2. 回单与其他附件刷新后可预览、下载和软删除。
3. 往来方向编辑后资金汇总同步切换且不重复计数。
