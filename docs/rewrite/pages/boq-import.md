# 合同工程量清单导入 — 7 份真实合同的格式分析与拆分策略

> 源文件：`docs/现实合同/`（gitignored）· 扫描时间 2026-07-03 · 供 #38 清单管理页「上传→拆表」实现用
> 术语：CONTEXT.md（合同工程量清单/三量/单价双轨）

## 一、格式分组（5 类）

| 类 | 文件 | 结构特征 |
|---|---|---|
| A 户型矩阵招标型 | 18/19/21招标清单 · 领秀海5/6# · 利丰北1-4# | 三级合并表头，行=分项，列=户型/层区横排单套量；部位列=房间；人工/辅材/主材单价拆分；【户型】/【公区】×装修/安装 多sheet |
| B 章节树户内合同型 | 合和七期 | 章节→材料做法节(CT/PT/ST编号)→「于XX房间」数据行，房间藏于文本；单户量×楼栋组户数系数 |
| C 结构化数字清单型 | 清单.xlsx | I列行类型状态机(A1章/BQDESC/BQITEM/TOTAL)+GUID追溯键+部位属性列，最规整 |
| D 楼层分部国标型 | 车陂商业 | 单项工程sheet→楼层行→分部→清单项；无户型无房间；价拆主/辅/人工/管理费 |
| E 单价库型 | 零星维修 | 量恒为1，无空间维度，导入后作**分项单价库** |

## 二、统一目标模型（清单行）

- **必有**：分项名称 / 单位 / 工程量 / 合同单价 / 合价 / 来源追溯键(文件·sheet·行)
- **常有可空**：楼栋 / 户型 / 套数(倍数) / 房间(部位) / 分部·章节 / 楼层层区 / 特征描述
- **可选**：材料编号 / 品牌 / 采购方式(甲/乙供) / 人工费 / 辅材机械费 / 主材单价·损耗·主材费 / 管理费 / 税率 / 含税标记 / 量口径(单套|总量)

## 三、批量拆分策略

- **规则解析**：C(状态机)；A 族一套解析器(sheet名正则分类+三级表头展开户型列+合并单元格前向填充+合计行过滤)；E 直接入单价库
- **AI 辅助**：B/D 的房间从「于XX」/特征文本提取；跨文件表头→统一字段列映射；列位漂移修正
- **人工确认节点**：户型列↔套数对应(对照汇总表)；单套量×套数≠总量差额；D/E 房间派量；镜像/变异户型归并；零量行/补充区取舍

## 四、逐文件解析要点

- **18/19/21招标**：sheet名正则分组；跳1行标题，R2-R4三级表头展开户型/楼层列；部位列直接给房间；难点=合并单元格前向填充、隐藏空列极多(公区258列)、尾部合计过滤
- **领秀海**：11清单sheet；R2-R4多级表头定位固定列+动态户型列组；章节行(一/二=房间)+分部行建目录树；安装sheet列位漂移+2列
- **利丰北**：定位「序号」表头行，下2行读户型/层区列+套数行；中文序号=房间章节、数字序号=分项行；「02户型(04镜像)」注记
- **合和七期**：「交标」表；无序号无单位=章节/做法节，数据行「于+房间」与上方做法节拼接；单户量×户数系数行；WPS图片公式忽略
- **零星维修**：「基准价清单」两级章节+清单项；量全为1→入单价库；章节跳号不能靠连续性；多行长文本保留换行
- **清单.xlsx**：I列行类型状态机；部位属性列=房间；单户量×楼栋列×BQ-Sum倍数；GUID保留作追溯键；四级合并表头按列位硬编码
- **车陂商业**：sheet=单项工程；楼层行正则(负X层/首层)且量价空；三套列模板(12/13/9列)按表头文字动态映射；房间仅能从特征弱提取

## 四点五、拆表交互 —— 三步向导（反馈轮 7 grill 定稿）

入口：项目详情 Tab③ 清单附件「未拆表」chip → 进向导；或识别中心「清单拆表」页。样例文件 = **合和七期（B 类，最复杂）**，串起既有排程/矩阵演示数据。

```
① 上传识别格式 ─→ ② 人工确认页 ─→ ③ 拆表结果预览 ─→ 入库清单管理页
   自动判 A–E 类       聚合确认节点      统一清单行模型
   显示 sheet 清单     可改后继续        + 来源追溯键
```

- **步骤①**：拖拽/选文件 → 自动识别格式类（显示「已识别：B 类·章节树户内合同型 · N 个 sheet」），列出各 sheet 及推断用途（户型/公区、装修/安装）。
- **步骤②确认页**（§三「人工确认节点」可视化，全部可改）：户型×套数对照表（对照汇总表校验）、单套量×套数≠总量的**差额行黄色提示**、镜像/变异户型**归并建议**（勾选合并）、零量行/补充区取舍。数据错了会污染合同量唯一来源，故独立成页。
- **步骤③结果预览**：统一清单行模型表格（§二字段）+ 来源追溯键（文件·sheet·行）；确认后写入工程量清单管理页（#38，分部→工种→分项目录 + 三量）。
- 多 sheet：逐 sheet 在向导内按 §四逐文件解析要点处理；一份合同的多份清单文件各自独立走一遍向导。

## 五、已拍板口径（grill 定稿 2026-07-03）

1. **量口径**：单套量为准（×套数=系统总量），与清单总量列差额导入时提示人工确认；**镜像/变异户型归并**为同一户型
2. **单价**：不含税为主 + 税率字段，报量/产值按需换算含税（与发票税额体系一致）
3. **甲供材分项**：照常计工程量与人工（工资照算），材料成本不计入自身成本/毛利，导入时标「甲供」
4. **空间粒度随清单**：清单给到哪级管到哪级（商场无房间就到楼层/分部，照样勾完成算毛利），不强制派量到房间；需要时可选择性细拆
