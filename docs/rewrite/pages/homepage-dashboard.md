# 首页施工进度驾驶舱

> 路由：`/` · 页面：`app/pages/index.vue`
>
> 既有实现来源：[#189](https://github.com/zodea/crm-new/issues/189)；当前复核由 [#414](https://github.com/zodea/crm-new/issues/414) 承接，排程来源与 #412 联验。
>
> 关联权威：[施工进度 §7.1](schedule-progress.md)、[ProjectSwitcher 契约](../../design/kit-ui-component-specs.md)、[ADR 0013](../../adr/0013-align-all-ui-to-online-design.md)

首页是当前项目施工进度的只读驾驶舱，不承担经营指标汇总。历史“五指标 + 四图表”、首页独立通知抽屉和虚构聚合数据方案已经删除，不得再作为实现依据。

## 1. 参考差异与裁定

2026-07-27 在用户已打开的登录态参考站中，按严格只读协议观察到：

| 参考首页直接证据 | 瑞航首页裁定 |
| --- | --- |
| 上方为待办、周历日程、公告，当前均为空 | 不复制。瑞航没有与这些门户面板一一对应且可验证的首页事实；通知统一由应用外壳负责 |
| 下方为“项目信息、目标成本、付款申请、费用报销”四个快捷入口 | 不复制。现行首页只服务当前项目施工排程；业务入口继续由侧栏与对应领域页面承载 |
| 未见项目切换器 | 保留统一 `ProjectSwitcher`，因为施工进度是项目级事实 |
| 未见施工进度甘特 | 按 `DC重构设计源码/kit/HomeScreenNew.jsx` 和施工进度蓝本重绘 |
| 未见经营指标卡或统计图表 | 瑞航同样不展示；没有真实口径的数据不得以 0、模拟值或推断值补齐 |

直接对应的门户模块以参考站为证据；瑞航独有的项目排程能力以 DC 设计和领域蓝本为证据。该裁定没有引入参考站不存在的业务规则，也没有改变任何写入路径。

## 2. 页面结构

页面只保留两个层级：

1. 项目导航行：统一 `ProjectSwitcher` + “全部项目”入口。
2. 当前项目施工进度：部分数据提示（如有）+ 统一施工进度甘特。

施工进度头部显示整体计划偏差、计划起止日期、只读说明和“打开施工进度”入口。甘特按楼栋分组展示工序、计划区间、实际完成、今天线和工程量下钻标识。

## 3. 数据与状态

页面消费 `useScheduleStore` / `ScheduleProjectView` 提供的排程投影，不在页面构造业务指标或模拟事实。项目目录与已接管领域必须由同来源中央 Repository 提供，不能因复用旧 store 回退本地项目；#412 / #414 联验来源、缺源与刷新回读，前台可用不等于生产部署完成。

| 状态 | 页面反馈 | 可恢复路径 |
| --- | --- | --- |
| `loading` | 施工进度骨架屏 | 等待同一请求完成 |
| `catalog-empty` | 尚无可查看项目 | 前往整页项目表单 |
| `schedule-empty` | 当前项目没有施工排程 | 新建楼栋分组或打开施工进度 |
| `partial-data` | 保留已有进度，同时显示缺失分组/适用单元提示 | 前往施工进度补齐配置；缺失值不按 0 推断 |
| `error` | 明确错误说明 | 重新加载 |
| `ready` | 项目进度甘特 | 项目切换、分组展开、工序下钻 |

部分数据不是独立空页：只要存在可用排程，就继续展示已知事实，并用非阻断提示说明覆盖缺口。

## 4. 交互闭环

### 项目切换

- 项目选择器在 1、3、12 个项目时使用同一触发器和搜索面板契约。
- 只有目标项目读取成功后才确认选择并同步 `?project=`。
- 切换失败时恢复上一个已确认项目、上一个可用快照和 URL；页面内显示可重试错误，系统泳道同时提示结果。
- 并发切换只接受最后一次请求结果，较早响应不得覆盖当前选择。
- 路由查询变化和页签重新激活都重新核对项目事实，不能只依赖首次挂载。

### 甘特

- 楼栋分组可展开/收起；高亮分组或工序时自动保证对应分组展开。
- 工程量联动工序跳转到工程量工作台并携带项目、分组和工序筛选。
- 手动填报工序不伪造下钻，提示用户前往施工进度页维护。
- 首页本身只读；新增分组、编辑计划和进度写入均在施工进度路由完成。

## 5. 响应式与可达性

- 在 390、768、1024、1440px 验证项目切换、状态反馈、分组展开和工序下钻。
- 页面不得产生横向滚动；甘特时间轴只在 `[data-testid="home-schedule-scroll"]` 内横向滚动。
- 项目导航允许收缩但不隐藏“全部项目”；移动端项目选择使用全屏 Dialog。
- 甘特滚动区可聚焦，键盘焦点可见；状态面板使用 `status` / `alert` 和对应 live region。
- 今天线、状态色和图例不能仅靠文字位置表达，计划/实际/逾期仍保留不同形状或线型。
