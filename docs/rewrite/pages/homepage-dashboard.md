### 指标卡片行 `MetricCards` — 5列

| 卡片 | 主数值 | 补充 |
|---|---|---|
| 合同总额 | 施工+变更合计 | "施工 ¥X万 · 变更 ¥X万" |
| 累计收款 | 甲方收款合计 | 回款率 = 收款/合同 |
| 累计支出 | 所有支出合计 | "材料 + 分包 + 人工" |
| 已开票 | 已开票金额 | 税额 ¥X万 |
| 利润率 | (收款-支出)/收款 | 较上月变化 ↑/↓ |

### A: 月度支出柱状图 `MonthlyExpenseChart`

- **图表类型**: 堆叠柱状图
- **X轴**: 近 6 个月（可切换 6/12 个月）
- **Y轴**: 万元
- **堆叠分段**: 材料采购(蓝) + 分包费用(橙) + 人工工资(绿) + 其他(灰)
- **每根柱子**: 内部按分类堆叠，顶部显示该月支出总额
- **交互**: hover 显示各分类明细金额，点击某月 → 跳转该月支出列表
- **占比**: 左侧 55%

### B: 支出构成饼图 `ExpensePieChart`

- **图表类型**: 环形图（Donut）
- **分类**: 材料采购、分包费用、人工工资、其他费用
- **中心文字**: 总支出金额
- **图例**: 下方 2×2 网格，每项: 色块 + 分类名 + 金额
- **交互**: hover 高亮扇区显示占比，点击 → 跳转对应支出列表
- **数据范围**: 当前选中项目的累计数据（不按月份，是总额）
- **占比**: 右侧 45%

---

### C: 票据与税额柱状图 `InvoiceTaxChart`

- **图表类型**: 柱状图
- **柱子**: 已开专票、已开普票、已收发票、进销差额
- **颜色**: 前三用蓝色系（深→浅），差额用橙色
- **标注**: 每根柱子顶部显示金额数值
- **底部文字**: "进销差额: ¥689万"
- **交互**: 点击柱子 → 跳转 `/finance/invoice` 或 `/finance/ticket`
- **占比**: 左侧 45%

### D: 施工进度甘特图 `ConstructionGanttChart`

- **图表类型**: 施工进度计划表（横向甘特图）
- **参考**: 合和新城7期施工进度计划表（户内）格式
- **占比**: 右侧 55%

#### Y轴（左侧固定列）

| 列 | 说明 |
|---|---|
| 楼栋/区域 | 按楼栋分组（1栋/2栋/3栋/公区），每组下标注楼层范围（33F-39F） |
| 分项工程 | 砌体砌筑、内墙抹灰、防水工程、墙地砖铺贴、水电安装、门窗安装、电梯厅装修、楼梯间涂料、屋面防水、外墙涂料 |

- 两列固定在左侧（sticky），不随横向滚动

#### X轴（月份时间轴）

- 双行表头：上行月份（合并3列），下行上/中/下旬
- 横向可滚动（项目跨度长时自动出现滚动条）
- 右上角可切换时间范围：全部 / 近6月 / 近3月

#### 横条（工序条形）

- 每种工序一种颜色，条的起止位置对应施工开始/结束旬
- 条内可显示简短标签（工序名）
- 不同楼栋同一工序颜色一致，方便对比

#### 与工程量模块的数据关系

| 维度 | 首页甘特图 | 工程量矩阵 `/subcontract/quantity` |
|---|---|---|
| 行 | 楼栋×楼层段×分项工序 | 楼层×户号×分项 |
| 列 | 月份旬（时间轴） | 工人 |
| 格子值 | 计划时间跨度（条形） | 实际工程量（m²/m/套） |
| 视角 | **计划进度**（横轴是时间） | **施工明细**（谁做了哪间房） |

- 数据源: 工程量记录表（QuantityRecord）
- 甘特图根据每个分项工序最早/最晚施工记录自动计算条形起止
- 无需手动维护进度计划，从实际施工数据反推

#### 点击跳转

| 点击区域 | 跳转目标 | 携带参数 |
|---|---|---|
| 工序条形 | `/subcontract/quantity` | 项目+楼栋+楼层范围+分项工序筛选 |
| 楼栋名 | `/project/:pid` 项目详情 | 滚动到对应楼栋区域 |
| 条形 hover | tooltip: 工序名、楼栋楼层、计划起止、已完成量/总量、完成率 | — |

#### 右上角工具

- 时间范围切换: 全部 / 近6月 / 近3月
- 今日线: 红色竖虚线标注当前日期位置

## 图表技术方案

| 项 | 选型 |
|---|---|
| 图表库 | ECharts（按需引入） |
| 引入 | `echarts/core` + BarChart / PieChart / CustomChart |
| 甘特图 | ECharts custom series 或 `echarts-gantt`（自定义矩形渲染） |
| 渲染 | Canvas |
| 主题 | 自定义 theme 对齐 DESIGN-SYSTEM.md |
| 响应式 | `ResizeObserver` + `chart.resize()` |
| 空态 | 数据不足时灰色骨架 + "暂无数据" |

## 交互规范

### 项目切换

- 切换下拉框 → 指标卡片 + 4 个图表区块全部刷新
- 数据异步加载，图表区域显示 loading 动画
- "全部项目汇总" → 聚合所有在建项目数据

### 图表通用交互

- **hover**: tooltip 显示详细数值
- **点击**: 跳转到对应模块列表页（带筛选条件）
- **右上角工具**: 月份范围切换（近6月/12月）— 仅支出柱状图

### 跳转映射

| 点击区域 | 跳转目标 | 携带参数 |
|---|---|---|
| 指标"合同总额" | `/material/contract` | 当前项目 |
| 指标"累计收款" | `/finance/receipt` | 当前项目 |
| 指标"累计支出" | `/finance/payment` | 当前项目 |
| 支出柱状图某月 | `/finance/payment` | 当前项目+月份 |
| 支出饼图某分类 | `/finance/payment` | 当前项目+支出类型 |
| 票据柱子 | `/finance/invoice` 或 `/finance/ticket` | 当前项目+票据类型 |
| 甘特图工序条 | `/subcontract/quantity` | 项目+楼栋+楼层范围+分项工序 |
| 甘特图楼栋名 | `/project/:pid` | 滚动到对应楼栋 |
