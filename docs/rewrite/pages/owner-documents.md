# 主合同与分包单据 — 变更/报量/验收/结算/罚扣

> 表单蓝本：`OwnerDocForms.jsx` 的 8 条整页路由  
> 持久化权威：`DATABASE.md`；BOQ 变更和月度报量同时受 #115 既有模型约束

## 一、甲方变更与月度报量

### 甲方变更 `ownerChangeForm`

| 分区 | 字段与规则 |
|---|---|
| 基本信息 | 变更编号、变更名称*、项目*、施工合同*、类型、甲方指令单编号、指令类型、申报日期* |
| 金额 | 含税审定金额、无税审定金额、无税申报金额；与量价明细合计展示勾稽 |
| 变更明细 | 分项*、单位、调量差值、调价后单价、变更合价、备注 |
| 事由与流转 | 变更事由*、状态说明、四态生命周期 |
| 附件 | 我方指令单、甲方指令单、报价与算量、施工照片 |

量价变更复用 `boq_change_orders` / `boq_change_lines`，不得再建 `ownerChanges` 副本；纯金额签证才直接进入业主变洽签台账。已签证金额的更正遵守二次确认与后续金额链保护。

### 甲方报量 `ownerReportForm`

报量编号、项目*、施工合同*、报量期次*、申报日期、申报产值、审定产值、审定差额只读、报量明细、状态、备注和扫描件。报量明细从月度报量草稿生成，人工调整和甲方审定值均留痕；不得复制另一套完成事实。

## 二、竣工验收与最终结算

| 表单 | 字段与规则 |
|---|---|
| 竣工验收·保修 `acceptanceForm` | 单据编号、类型、名称*、项目*、施工合同、日期*、合同估价、验收人、保修负责人、验收结论、状态、备注、验收资料 |
| 最终结算 `finalSettleForm` | 结算编号、结算名称*、项目*、施工合同、结算金额*、报审日期*、变更后合同金额/累计收款/结算收款差额只读、结算依据、差异说明、状态、备注、结算书 |

验收和保修是同一单据的类型与状态流转；最终结算独立保存甲方审定事实，不复用支出结算。

## 三、罚扣与分包单据

| 表单 | 字段与规则 |
|---|---|
| 甲方罚扣 `ownerPenaltyForm` | 罚扣编号、项目*、施工合同、联系单编号、罚扣金额*、日期*、罚扣事由*、申诉说明、状态、备注、联系单扫描件 |
| 分包变更 `subChangeForm` | 变更编号、类型、项目*、分供方*、支出合同*、日期*、审批金额*、变更面积、实际审定价、事由*、状态、备注、签证单 |
| 分包结算 `subSettleForm` | 结算编号、结算名称*、项目*、分供方*、支出合同*、结算类型、结算金额*、日期*、合同金额/往期结算/占比只读、扣款说明、状态、备注、结算单 |
| 项目罚扣 `projPenaltyForm` | 罚扣编号、项目*、分供方、支出合同、班组、日期*、罚扣事由*、罚扣金额*、扣除方式、整改期限、整改说明、状态、备注、罚款照片 |

分包、材料和其他支出结算统一写 `expenditure_settlements`。项目罚扣可指向分供方、合同或班组；抵扣动作必须引用真实结算，不在罚扣头维护“已扣金额”副本。

## 四、共同规则

- 项目、合同、客户/分供方和班组 lookup 保存真实 ID。
- 明细网格落子表，附件走 `file_refs`。
- 草稿允许不完整；提交、确认、签证和审定动作按各自状态校验。
- 只读带出和聚合金额不保存；具有审计价值的申报、审定、申诉和整改结果保存。

## 五、验收

1. 8 条表单路由均能从列表新建、从详情编辑并在页签切换后保值。
2. BOQ 变更、月度报量和支出结算复用既有权威实体，无 mock 副本。
3. 状态动作、明细、附件和金额勾稽刷新后可追溯。
