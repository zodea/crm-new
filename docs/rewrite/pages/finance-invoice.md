## 一、InvoiceView 四阶段

### 阶段 Tab（sticky 顶栏）

```
[文档识别状态 28]  [发票识别与校对 12]  [待入账 12]  [已入账 8]
```

### 数据分区（修复后）

| Tab | 数据过滤条件 | 用途 |
|-----|-------------|------|
| 文档识别状态 | `accountStatus ≠ posted`（所有未入账） | 上传、识别、文件管理 |
| 发票识别与校对 | `status = done && accountStatus ≠ posted` | 逐张校对编辑字段 |
| 待入账 | 同上（与校对同源，不同 UI） | 批量入账操作 |
| 已入账 | `status = done && accountStatus = posted` | 归档、查阅 |

### 关键修复（2025-06-25）

1. `recognizedItems` 排除 `accountStatus === "posted"`
2. `postedItems` 独立从 `allSorted` 派生
3. review 内子筛选只保留"全部"和"提取不全"
4. 编辑入口统一为 `editSingle()`，不再跳 `/finance/invoice/:id`

## 二、开票因子计算器重构

### 当前问题

| # | 问题 |
|---|------|
| 1 | 提示小字过多 |
| 2 | 复制区(6行)与汇总卡片(3张)功能重复 |
| 3 | 因子表和组合方案垂直堆叠，应左右联动 |
| 4 | 因子表列过多：锁定/数量/小计/合计/差额无用 |
| 5 | 无法从 Excel 粘贴导入 |

### 新布局：两行两列

```
┌─── Row 1 ─────────────────────────────────────────────────────────────┐
│  ┌─ 输入面板 ──────────┐    ┌─ 金额卡片 (3列，唯一复制入口) ────────┐ │
│  │ 目标含税金额         │    │ 价税合计  │ 不含税金额 │ 税额         │ │
│  │ 税率 [13][9][6][3][1]│    │ ¥128,640 │ ¥113,841  │ ¥14,799     │ │
│  │ 小数位               │    │ 大写(复制)│ 大写(复制) │ 大写(复制)  │ │
│  └──────────────────────┘    └─────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────┘
┌─── Row 2 ─────────────────────────────────────────────────────────────┐
│  ┌─ 开票因子 ──────────────────┐  ┌─ 组合方案 ────────────────────┐  │
│  │ 名称 │ 单位 │ 单价 │ 上限 │删│  │ [计算组合]  最多 N 条         │  │
│  │ [+ 新增]  [粘贴导入]        │  │ 共 N 种 · Xms                │  │
│  └──────────────────────────────┘  └─────────────────────────────┘  │
└───────────────────────────────────────────────────────────────────────┘
```

### 因子表精简

保留：名称、单位、含税单价、上限、删除
删除：锁定、数量、小计、合计行、差额行

### 粘贴导入

格式：Tab 分隔，每行一个因子（名称 \t 单位 \t 单价 [\t 上限]）

入口：
1. 全局 `Ctrl+V`（焦点在因子区域时自动解析）
2. "粘贴导入" 按钮弹 textarea

### 删除的 JS 逻辑

`lockedTotal, remainAmount, unlockedFactors, allocatedResults, allocatedTotal, diff, toggleLock` 以及因子的 `{ locked, qty }` 字段。
