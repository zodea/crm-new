# 开票申请 — 我方向客户开票

> 表单蓝本：`invApplyForm`  
> 持久化权威：`DATABASE.md` 的 `invoice_applications` / `file_refs`

## 新增/编辑

| 分区 | 字段与规则 |
|---|---|
| 基本信息 | 申请编号、开票申请名称*、项目*、施工合同（项目级联）、购方客户、购方税号、发票类型 |
| 金额与税率 | 开票金额*、税率、税额、价税合计（只读派生） |
| 开票内容 | 开票内容、票面备注 |
| 经办与审批 | 申请人、申请日期*、状态、附件 |

项目、施工合同和购方保存真实 ID。购方税号是申请时快照，客户档案后改不追溯已提交申请。价税合计只读，不另存第二份可编辑值。

## 生命周期

`草稿 → 审批中 → 已审批 → 已开票`。草稿允许缺业务字段；提交时校验项目、名称、日期、金额和购方信息；“已开票”必须关联实际销项票据或留存开票结果附件。

## 验收

1. 合同 lookup 按项目过滤且保存真实合同 ID。
2. 金额、税率、税额修改后价税合计即时更新。
3. 已提交记录刷新后字段、状态与附件保持。
