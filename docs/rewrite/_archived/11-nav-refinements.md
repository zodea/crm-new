# 决策 11：导航结构细化

## 确认项

### 1. 首页 → 项目详情跳转

首页是在建工程总览仪表盘，Tab 切换不同项目，展示收付款/工程量/税额面板。
点击项目名称 → 跳转项目信息/项目详情页。确认无误。

### 2.「基础信息」改名 + 工人归入

原「基础信息」只有分供方和班组，现需加入工人（人工）。
三者都是业务运转前需要建档的底层数据（谁 = 单位 + 团队 + 个人）。

子项：
- 分供方（单位档案）
- 班组（团队档案）
- 工人（人员档案）

名称待定，候选：基础档案 / 人员与单位 / 资源档案

### 3. 分组逻辑 = 按业务类型，不按合同类型

各业务域自带各自的合同，不单独抽出"合同管理"分组：
- **主合同管理** → 甲方签订的工程合同
- **分包及人工** → 与劳务分供方签订的分包合同
- **乙供材管理** → 与材料分供方签订的采购合同

合同是各业务域内的环节，不是独立的一级分类。
