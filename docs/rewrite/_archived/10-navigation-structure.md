# 决策 10：导航结构 — 参照红圈CRM系统

## 一级菜单（7 项）

### 1. 首页（新增）

- 各在建工程项目状况总览
- Tab 页切换不同项目
- 面板内容：收付款、施工工程量、税额等
- 点击项目名称 → 跳转项目详情

### 2. 项目信息

- 项目清单列表
- 点击进入项目详情
- 项目详情内含：详细资料、成本预算、施工合同、支出合同、票税、资金等

### 3. 基础信息

子项：
- **分供方** — 现有分供方资料库
- **班组** — 班组管理（全局实体，跨项目复用）

### 4. 资金管理

子项：
- **开票申请** — 待设计
- **收款登记** — 待设计
- **收票登记** — 待设计
- **付款申请** — 待设计
- **费用报销** — 现有发票费用报销导出可整合
- **支付记录** — 待设计

> 现有的「发票识别」和「开票因子计算」归入此分组

### 5. 主合同管理（新增）

和甲方签订的工程合同。参照红圈系统子项全部保留：
- **施工合同**
- **甲方报量**
- **甲方罚扣单**
- **甲方变洽签** — 合同金额调整
- **竣工验收**
- **最终结算**
- **保修到期确认单**

### 6. 分包及人工

子项：
- **分包合同** — 与分供方中做劳务的公司签订
- **项目罚扣**
- **分包结算**
- **变洽签** — 分包合同金额调整
- **工程量管理** — 按班组区分，矩阵可视化（上一版讨论的重点，界面需完善）
- **工资核算** — 计件/计时
- **考勤管理**

> 工程量管理从原「项目」分组移到这里，因为按班组区分更合理

### 7. 乙供材管理

子项：
- **采购合同** — 与分供方的材料商签订（不同于主合同/分包合同）
- **送货单识别** — 现有 OCR 识别整理功能
- **单价对比** — 现有跨供应商比价

> 不需要「下料单」，用送货单识别代替

## 与上一版草案的变化

| 上一版草案 | 本版定稿 | 变化 |
|-----------|---------|------|
| 无首页 | 新增首页（项目总览面板） | 新增 |
| 项目管理（项目+工地+项目×分供方） | 项目信息（纯列表+详情） | 简化，项目×分供方流转移到分包 |
| 合同管理（新增） | 主合同管理（甲方合同） | 改名+明确是甲方合同 |
| 材料管理（送货单+单价对比） | 乙供材管理（采购合同+送货单+单价对比） | 加入采购合同 |
| 财务管理（发票+收票+付款+报销） | 资金管理（开票+收款+收票+付款+报销+支付记录） | 改名+扩充子项 |
| 基础信息（仅分供方） | 基础信息（分供方+班组） | 班组归入基础信息 |
| 班组与工程（V2 整组） | 分包及人工（分包合同+罚扣+结算+变洽签+工程量+工资+考勤） | 重组，加入分包合同相关 |
