# 红圈CRM 内容区设计模式参考

> 从红圈CRM截图中提取的交互模式与布局规则。  
> **适用范围**：仅内容区（右侧主体）。外壳视觉见 [ADR 0013](../adr/0013-align-all-ui-to-online-design.md)（中文方块白底侧栏回归、毛玻璃侧栏仍废弃），外壳行为见 [ADR 0011](../adr/0011-redesign-application-shell.md)。
> 色值/组件样式: → `DESIGN-SYSTEM.md`（本文件只管布局模式，不定义色值）  
> CRM 截图: `docs/红圈系统/`
>
> ⚠️ **形状基准已变更（ADR 0007）**：本文沿用红圈的**扁平形状**（无圆角/无阴影/直角网格/纯 1px 边框）描述已废弃，内容区改为**圆角卡片 + 阴影现代风**。仍然有效的是本文的**布局模式**——面包屑 Tab、列组切换、列头筛选、底部汇总、详情 70/30、Section 网格、审批时间线等；作废的只是"扁平形状"。凡本文出现"无圆角/直角/不使用阴影"，一律以 ADR 0007 为准。
> ⚠️ **比例只表示宽屏构图**：本文示意图中的 70/30、五格、三列、两列均不是固定画布或全宽度锁列。现行响应式契约以 [ADR 0013](../adr/0013-align-all-ui-to-online-design.md) 为准；空间不足时必须降列、堆叠或转 Sheet。

## § 1 列表页

### 1.1 顶部面包屑 + Tab

```
全部合同分组 > 分供方 > [材料采购合同] [请购/支出合同] [项目信息]
```

- 面包屑路径用 `>` 分隔，蓝色可点击
- 同级分类用 Tab 切换（下划线选中态），不用独立页面
- Tab 数量一般 3-5 个，代表同级业务分类

### 1.2 工具栏

```
[图标] 全部合同台账   [基础信息|累计信息|开票信息|结算状态]   MiniFilter搜索   [刷新][设置][筛选][导出][+新建]
```

| 元素 | 说明 |
|---|---|
| 标题 | 左侧，带图标，显示当前视图名称 |
| 列组切换 | 紧跟标题，方形按钮组（无圆角），选中态实色填充 |
| MiniFilter | 小型搜索框，文本输入即时筛选 |
| 操作按钮 | 右侧图标按钮行，方形 28px，1px 边框，最后一个（新建）用主色填充 |

### 1.3 数据表格

- **无圆角** — 表格面板直角，无 border-radius
- **网格线** — 列之间有竖线分隔（th 和 td 都有 border-right），形成完整网格
- **表头** — 浅灰背景 `#fafbfc`，字号 11px，加粗，深灰色
- **列头筛选** — 可筛选列显示漏斗图标 `▽`，可排序列显示双箭头 `↕`
- **状态文字** — 直接用颜色文字（绿色"履约中"、橙色"待审批"、红色"已终止"），**不用 chip/pill 背景色块**
- **链接** — 蓝色文字，hover 下划线
- **金额** — 等宽字体，右对齐，不加 ¥ 前缀（纯数字 + 千分位）
- **行高** — 紧凑，padding 7-8px
- **hover** — 浅灰背景 `#f5f7fa`

### 1.4 底部汇总栏

```
合同总计入经营报表: 18,386,216.46    累计变更合同金额: 14,993,279.45    |    [<] [1] [2] [3] [>]  共24条
```

- 左侧: 2-3 个关键汇总指标，加粗数值
- 右侧: 方形分页按钮 + 总条数
- 背景白色，顶部 1px 边线

## § 2 详情页

### 2.1 整体布局

```
┌─────────────────────────────────┬──────────────┐
│ 文档标题栏 + 操作图标              │              │
├─────────────────────────────────┤  审批时间线    │
│ 信息摘要行（5格横排）              │              │
├─────────────────────────────────┤──────────────│
│ 审批区 Tab（详情/变更/验收/付款...）│  评论区      │
├─────────────────────────────────┤              │
│ 增补合同表                        │──────────────│
├─────────────────────────────────┤  文件列表     │
│ 基础信息（3列网格）               │              │
├─────────────────────────────────┤──────────────│
│ 累计信息（3列网格）               │  跟进人      │
├─────────────────────────────────┤──────────────│
│ 开票方信息                        │  动态        │
├─────────────────────────────────┤              │
│ 质保金信息                        │              │
├─────────────────────────────────┤              │
│ 系统信息                          │              │
└─────────────────────────────────┴──────────────┘
```

宽屏构图约 **70% : 30%**；右栏用 `clamp()` / `minmax()` 设可读边界。容器不足时右栏移到主内容下方或转 Sheet，不保留固定 280–300px 并排画布。

### 2.2 文档标题栏

```
📋 车骏商业大楼项目-铝单板-顺利圆   ⭐ 🔗 🖨   [关闭 ×]   [打印] [日志] [操作按钮组]
```

- 文档名称 + 收藏/分享/打印图标
- 右侧：关闭按钮 + 功能按钮组

### 2.3 信息摘要行

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 项目名称   │ 签约日期   │ 乙方      │ 我方签名代表│ 管理部门   │
│ 合和新城   │ 2025/01/19│ 大板东建材 │ 陈志强     │ 采购部    │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

- 宽屏最多 5 格等宽，按容器最小可读宽度自动降列，1px 分隔
- 上方小字 label（灰色 9px），下方值（12px）
- 值中有链接的用蓝色

### 2.4 内容区 Tab

```
[详情内容] [变更合同通知] [物资验收] [付款信息] [合同结算]
```

- 下划线选中态，和列表页 Tab 样式统一
- 切换不同内容分区

### 2.5 表单网格（label-value）

```
┌──────────────┬──────────────┬──────────────┐
│ 项目名称       │ 付方地区      │ 合同状态      │
│ 车骏商业大楼   │ 广州市        │ 履约中(绿)    │
├──────────────┼──────────────┼──────────────┤
│ 甲方           │ 乙方          │ 材料采购方式  │
│ 瑞航建筑       │ 大板东建材    │ 月结          │
├──────────────┼──────────────┼──────────────┤
│ ...           │ ...          │ ...          │
└──────────────┴──────────────┴──────────────┘
```

- 宽屏最多 **3 列等宽**；容器不足时自动降为 2/1 列，仍保持完整分隔
- 每个单元格：上方 label（灰色 9px），下方 value（12px）
- 跨列时用 colspan
- 不同信息区用 section 标题分隔（如"基础信息"、"累计信息"）

### 2.6 Section 标题

```
━━ 基础信息
━━ 累计信息
━━ 预付款以及账情况
━━ 开票方信息
━━ 质保金信息
━━ 系统信息
```

- 无背景色，左侧有图标或竖线装饰
- 简洁文字，字号 12-13px，加粗

### 2.7 右侧边栏

#### 审批时间线

```
  🟢 陈志强        ← 圆形头像（姓氏首字+颜色底）
  │  已提交审批
  │  2025-01-19 11:43
  │
  🔵 赵工
  │  选择确认的合同处理工艺
  │  2025-01-19 11:07
  │
  🟢 古富联
  │  通过确认，确认签字
  │  2025-01-19 11:43
  │
  🟠 陈总监
  │  已验收上传附件
  │  2025-01-19 13:05
  ...
```

- 垂直时间线，头像圆圈 28px（姓氏首字，彩色背景）
- 连接线 1px
- 每项：姓名（加粗）→ 描述 → 时间戳

#### 评论区

- 标题 "评论 (N)"
- 已有评论：头像 + 姓名 + 内容 + 时间
- 输入框：textarea + 附件/表情图标 + 发表按钮

#### 文件列表

```
# │ 文件名        │ 文件大小 │ 上传人 │ 上传时间 │ 操作
1 │ 合同正本.pdf  │ 2.31 MB │ 陈志强 │ 2025... │ ...
```

- 小型表格，直角，紧凑
- 底部分页（共 N 条/N 页）

#### 跟进人 + 动态

- 跟进人：头像 + 姓名 + 职位，可编辑
- 动态：操作日志列表（谁在什么时间做了什么）

## § 3 新建/编辑表单

### 3.1 布局

```
┌────────────┬─────────────────────────────────────────┐
│ 左侧分区导航 │ 表单内容                                  │
│             │                                          │
│ ● 基础信息  │  !基础信息                                 │
│   合同条款  │  项目名称*  [下拉选择]    付方地区  [输入框]  │
│   开票方信息│  甲方*      [下拉选择]    乙方     [下拉选择] │
│   质保金信息│  合同编号*  [自动生成]    签约日期* [日期选择] │
│   采购合同明│  ...                                       │
│            │                                            │
│            │  !合同条款                                   │
│            │  主要条款    [多行文本]                       │
│            │  支付及结算方式 [多行文本]                    │
│            │  ...                                        │
│            │                                             │
│            │  底部: [保存快捷] [M/O关联] [重置] [保存草稿] │
│            │        [保存并新增] [保存]                    │
└────────────┴─────────────────────────────────────────────┘
```

### 3.2 左侧分区导航

- 垂直文字列表，当前区高亮（蓝色背景）
- 点击跳转到对应表单区域（锚点滚动）
- 宽屏 sticky 在左侧；容器不足时隐藏或转顶部选择器，表单区域自然流/局部滚动

### 3.3 表单字段

- 宽屏最多 **2 列布局**（label 在上，input 在下），字段最小可读宽度不足时自动单列
- 必填字段 label 带 `*`
- 输入框：直角，1px 边框，白色背景，带下拉箭头或日期图标
- Section 标题用 `!` 前缀 + 红色/品牌色文字
- 多行文本用 textarea

### 3.4 底部操作栏

```
[合同快捷操作]  [M/O] 已关联   [重置]  [保存草稿]  [保存并新增]  [保存]
```

- 固定在底部
- 多个操作按钮，"保存"用主色填充，其他用边框样式

## § 7 通用设计规则

| 规则 | 说明 |
|---|---|
| 圆角 | ~~内容区无圆角~~ → **卡片 `--radius-card` 12px**（ADR 0007）；按钮/输入 10px，小控件 8px。详见 `DESIGN-SYSTEM.md § 3.2` |
| 阴影 | ~~内容区不使用阴影~~ → **卡片用 `--shadow-card` 阴影**（ADR 0007），与 1px 边框叠加分层 |
| 毛玻璃 | 内容区**不使用** `backdrop-filter`；侧栏毛玻璃已废弃，外壳仅顶栏 blur(8px)（ADR 0013） |
| 边框 | 统一 `1px solid var(--line)` (`#d7e0ea`)，表格内部同 |
| 背景 | 页面 `var(--bg)` (`#f4f7fb`)，面板 `var(--panel)` (`#fff`)，表头 `var(--surface-2)` (`#edf2f7`) |
| 字体 | 正文基准 15px，表格/控件 14px，label 12px，标题 14-15px 加粗。详见 `DESIGN-SYSTEM.md § 5` |
| 状态色 | 列表页纯文字颜色，详情页/表单可用 chip 背景。详见 `DESIGN-SYSTEM.md § 4.5` |
| 金额 | 等宽字体 `var(--font-mono)`，右对齐，千分位，不加 ¥ |
| 链接 | 品牌蓝 `var(--brand)` 文字，hover 下划线 |
| 按钮 | `--radius-btn` 10px，28px 图标按钮，文字按钮 padding 少。详见 `DESIGN-SYSTEM.md § 4.2` |
| 分页 | 28px 页码按钮，`--radius-sm` 8px 圆角，选中态主色填充。详见 `DESIGN-SYSTEM.md § 4.14` |
| 筛选 | 列头漏斗图标下拉多选，不在工具栏做固定标签 |

## § 8 与现有APP的融合策略

**不变的部分:**
- 应用外壳：视觉以 [ADR 0013](../adr/0013-align-all-ui-to-online-design.md) 为准（中文方块白底侧栏回归、毛玻璃仍废弃），行为以 [ADR 0011](../adr/0011-redesign-application-shell.md) 为准
- 品牌锚点 `#3976C6` 与三类状态色保持不变；中性色与文字对比以 `DESIGN-SYSTEM.md` 当前令牌为准
- 组件样式详见 `DESIGN-SYSTEM.md § 4`

**采用红圈的部分（仅内容区布局与交互模式）:**
- 列表页: 面包屑Tab + 列组切换 + MiniFilter + 列头筛选 + 底部汇总分页
- 详情页: 信息摘要行 + Section网格 + 右侧审批/评论/文件
- 表单页: 宽屏左侧分区导航 + 最多 2 列表单 + 底部操作栏；窄屏隐藏/折叠锚点并切单列
- 弹窗: 可编辑表格 + 底部取消确定
- 通用: 内容区~~扁平（无圆角/无阴影）~~ → **圆角卡片 + 阴影**（ADR 0007），保留网格线/紧凑行高；外壳视觉见 ADR 0013、行为见 ADR 0011
