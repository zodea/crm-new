# 02 · 批 B — 资金域 + 全站蓝链

> 顺序：**2**（依赖批 A 的底座 + EntityLink + 合同实体）。公共上下文见 [HANDOFF.md](../../HANDOFF.md)。
> 用户点名优先项之一：**发票**。

## 目标

铺齐资金域全部单据列表，并把**全站实体名蓝链化真跳通**（发票、合同、项目、分供方到处能点）。做完＝资金链路（合同/结算 → 付款申请 → 付款管理 → 支付记录 ↘ 收票）在菜单里各有独立入口且互相蓝链。

## 1. 资金域列表（全走 `EntityListScreen` meta）

| 实体 | 蓝本 | 要点 |

| 付款申请 | 红圈08 付款申请 | **新建先选 8 业务类型**（有/无合同人材料分包、预付款、管理费、项目费用、公司付款）；列：申请/本期批复/实际支付 三金额 + 成本预算(蓝链) + 支付状态chip；默认视图「待追回发票付款申请」 |

## 2. 全站蓝链补全（EntityLink 铺开）

按蓝链去向表（grilling R1 Artifact 图1）把这些**已有页面**的实体名换成 `EntityLink`：
- **发票台账 / 发票编辑**：项目名、供应商、合同名 蓝链。
- **项目详情所有子表**（P1 的 10 Tab）：合同名→合同详情、供应商→分供方/工作台、发票号→发票编辑、成本科目→目标成本（批C）、单据号→单据速览。
- **项目×分供方工作台**（P2）：合同/请款/收票/付款行的实体名蓝链。

## 3. 金额穿透（铁律④）
