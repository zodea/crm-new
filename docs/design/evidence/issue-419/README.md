## 已落实范围

- 公共外壳：紧凑深色侧栏、单行菜单、顶部与页签尺寸按当前裁决对应；保留瑞航品牌、业务入口与必要状态。
- 分供方：默认完整适用列、单行名称链接、四种真实资料状态的小型浅底标签；文本、枚举和数值列头显示实际可用的筛选/排序入口；搜索、列条件、排序、分页共用全量查询。导入、新建、刷新、筛选、列设置均有真实流程。

- 主合同、材料合同与分包合同涉及的详情和表单：删除冗余常驻开发说明，保留实际业务反馈。
