# #450 本机客户磁盘保存验收

日期：2026-09-22。规格见 [Issue #450](https://github.com/zodea/crm-new/issues/450)、[ADR 0021](../../../adr/0021-single-operator-windows-production-storage.md)；操作见[本机客户指南](../../../guides/local-customer-storage.md)。本记录只报告隔离合成工作区的实际结果，不代表正式资料已启用。

## 实际运行

使用固定 Node `24.12.0` 的内置 SQLite、Nuxt 构建产物和 Chromium。验收脚本自行选择本机空闲端口、创建独立合成目录，先后终止并重新启动自己创建的两个服务进程；未连接日常 `3100` 端口或用户数据库。每次进程重启需重新登录。

最终独立浏览器验收：`e2e/production-customer-storage.spec.ts`，1 场景通过，场景 14.0 秒、总计 15.0 秒，浏览器未捕获页面异常。

- 访问码键盘登录；登录、客户表单和详情在 390 / 768 / 1024 / 1280 / 1440px 无页面级横向溢出。
- 客户字段与真实附件输入后，使第 60 秒状态请求返回 503；操作被遮挡，重试后原字段和文件仍在。
- 公开创建请求在服务端实际提交后故意丢失响应。浏览器仅保留原提交编号，停止服务并冷启动后从列表恢复入口回读原客户；客户没有重复创建，附件没有重复加入。
- 下载实际原件并核对字节和 SHA-256；更正客户版本后再次读回。软删除确认可以取消，焦点返回发起按钮。
- 删除后再次停止、启动、登录；已删除列表读取同一客户，恢复版本及原件，审计依次包含创建、更正、删除、恢复。返回正常列表不残留已删除缓存。
- 退出后访问业务接口被拒绝；尚未接管的工资接口仍拒绝。最后直接读取合成库确认只有一条客户。

## 行为与边界验证

- 生产存储、认证、HTTP、原键恢复及旧多页签定向验证：9 文件、24 用例通过；最后组件/恢复/HTTP 边界复验：3 文件、4 用例通过。
- 提交前故障通过同库审计写入故障验证整个事务回滚；提交后失响应通过真实公开请求验证。重复键异文、陈旧版本、权限撤销、伪造操作者、跨客户原件、跨数据来源均拒绝。
- 缺失目录、不可写、损坏、过新版本、工作区/维护人/用途错配均拒绝，无内存回退；用途为 `production` 时业务写入等待 PG-02 基线备份，不能用环境切换接管验证库。
- 类型检查、变更文件 ESLint、补丁格式检查、最终构建通过。没有新增生产依赖，没有调用 GitHub Actions。
- 独立 Standards / Spec 审查：服务端由 root、前端由 remaining_issue_frontier 复核，均无剩余阻断。原先生产宽松请求封套、不可恢复命令编号、临时状态错误卸载草稿三个问题均有失败复现及修复后验证；完整浏览器又暴露恢复返回列表旧缓存，已修并复验。

完整回归在合入最新主线后的冻结提交执行，结果在交付前补入本记录。先行检查点提交只封存工作，不以跳过重复 hook 充当测试通过。
