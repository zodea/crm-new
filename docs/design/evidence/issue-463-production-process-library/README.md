## 本次结果

完整不可变版本、工序顺序/前置 key/禁用状态、阶段与分项定义、同编码版本号、原命令及回执、审计和目录修订在同一 SQLite 事务提交。公开列表与详情每次从磁盘完整核对后返回，不保留第二份可独立改写的内存权威；旧的领域规则仅消费当次事务读取的状态。旧版本 ID 不变，新版本不会改写旧正文，空库不种演示模板。

本机模式只开放精确列表、详情和创建版本路由，访问码会话注入真实维护人；来源、身份、权限、陈旧基准与同键异正文均按既有规则拒绝。损坏版本、命令或审计不筛掉坏行，整体停止读写。正式 WBS 尚未接管时引用数量保持未知，不假报零。

共享 schema 保持 v1 引导冻结，以显式 v1→v2 追加 `process-library:1`；客户事实不变，升级失败回滚。参与者及所有预期实表通过同一 manifest 核对。备份窄接口只生成本机新建一致副本；#451 负责后续核验、独立介质发布与恢复，正式用途业务写门禁仍关闭。
