# #418 页面层次与排版复核

日期：2026-09-08。任务与差异依据见 [#418](https://github.com/zodea/crm-new/issues/418)，所属公共界面复核为 [#404](https://github.com/zodea/crm-new/issues/404)。实现从 `origin/main` 的 `4292291d` 接入已确认的复核文档；UI 审查固定点为 `322915ed`。

## 参考观察

本次在用户已登录的红圈中只切换既有分供方列表、详情页签并滚动读取。桌面现有窗口中可直接观察到：列表工具与表格连续；详情紧凑标题和简要资料在上、业务页签在资料分区之前，白底标签和值按列排布，辅助信息在右。未逐像素测量，未触发新增、编辑、保存、文件、审批等动作，未留存或发布参考站业务值及截图。

资料位置和层级使用本次直接观察；公共表单继续使用登记册 `R-FORM-LIVE` 已有直接证据。本次没有新增参考表单观察。品牌和整页表单边界继续遵守 ADR 0013 / 0014。

## 本批已落实

- 材料公共列表的 9 类、资金公共列表的 6 类，加施工合同、材料采购合同、项目、分供方列表，接入连续列表结构。标题、操作、筛选、原表格和汇总保持同一工作面；保留各自领域列与行为。
- 分供方详情默认“详细资料”，分基础、联系人、开票三个区块；其余业务页签直接显示对应明细。合作金额与档案信息在宽屏辅助区呈现，窄屏移到主区域之后；点击蓝色汇总会切换、定位并聚焦对应页签。
- 辅助区使用当前可读的合作、档案及其他支出合同入口。参考站中的审批、评论和文件能力没有对应可用事实，因此没有作为本批可用功能加入。这是瑞航现有功能范围下的编排决定。
- 资金和材料表单复用公共壳，最多两列字段，宽容器且有足够分区时显示导航；保留校验、脏状态和保存动作。合同字段继承同一列数规则。
- 指标网格尾行空余部分保持白底；列表使用不截获滚动祖先的裁剪；表单分区导航仅定位当前实例，避免同名分区串页。

详细结构只看 [组件规格](../../kit-ui-component-specs.md)、[公共页面结构](../../../rewrite/DESIGN-SYSTEM.md#a01-business-patterns) 和[分供方页面](../../../rewrite/pages/base-supplier.md)，不在此复制字段合同；原 CRM-PATTERNS 的历史内容由 Git 定位。
