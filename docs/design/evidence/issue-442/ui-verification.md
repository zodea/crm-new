## 已修复的可失败问题

- 新增 BOQ 列曾把录入来源选择框挤到 19.5px。运行断言先失败，修正最小列宽后五档均大于等于 100px。
- 冷刷新曾进入未接入的只读恢复；现按当前 Repository 核验项目、户、来源与权限，筛选白名单保留班组视角及责任人参数。
- A 阶段照片读取中切到 B，迟到文件不得加入 B 草稿，已有组件红绿验证。
- 归档确认等待期间切项目，以及新项目目录仍未返回的窗口，旧确认不得写新项目或旧项目。确认绑定项目、来源、快照和初始化序号；归档及来源组件最终 5 项包含分类反例，全部通过。[归档留证](https://github.com/zodea/crm-new/issues/442#issuecomment-5644306128)。
- 中央读取延迟 6.5 秒时，旧台账流程未及时选择目录，实际浏览器先红；复用惰性正文后先选择目录，仍在用户激活期间，随后读取并成功写出。项目与来源在读取前后复核。[慢读取留证](https://github.com/zodea/crm-new/issues/442#issuecomment-5644378794)。
- 分类导出准备期间切项目且新目录待回时，旧配置曾迟到打开。新增独立反例后，读取后的页面与来源校验阻止该结果；已经打开的独立导出配置仍可继续。

最后相关定向工作簿、来源和组件 **3 文件 13 项通过**，精确规范检查 **5 文件通过**。归档、台账惰性读取、分类准备来源三处尾差均经过独立 Standards / Spec 窄复核，无残余 P1/P2。

前置夹具曾遗漏班组联系人和工人银行字段，以及用数字现场量配空算式；均按现行命令规则修正。分类目录夹具曾将所有候选文件误报已存在，触发正常防覆盖循环；改为按空目录返回 NotFoundError 后真实写出通过。未放宽产品规则或既有金额断言。
