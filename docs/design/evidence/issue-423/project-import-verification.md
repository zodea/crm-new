浏览器使用当前 Nuxt 服务、Chromium 和每例独立 `x-ruihang-test-session`；前后分别重置项目与客户实例。测试自造 Excel，包含说明页、空白辅助 Sheet、标题行、空行和业务行，选择 `项目423` 后原始行号保持 4。系统自带 `project-real-320` 不计为本例创建行，所有数量断言只计隔离合成身份。没有生产资料、外部参考站写入或实际数据库迁移。

| 场景 | 已观察结果 |
| --- | --- |
| 项目列表入口与历史深链 | 都走中央 ProjectCommandStore/Repository/HTTP；成功保存回读后返回列表，名称可进入详情并刷新 |
| 稳定关系 | 客户 ID 优先、唯一名称/别名可解析，候选超过 100 条继续分页；同名歧义、缺失与演示候选拒绝；次客户同样校验 |

| 失效与权限 | 预览后客户改名仍保存原 ID；删除、明确 inactive 停用、中央权限撤回按行拒绝，不推断其他未知状态为停用 |
